# 管理対象バックエンド拡張

固定ブラウザの基準は `e75ae371ad777ffd1eecdd28d2781a6519b05591`。そのソースは変更せず、別コピーに管理対象の拡張を適用し、固定したLinuxコンテナ内で試験・ビルドする。バックエンドをmacOS上で直接実行しない。

互換パス、パッチ適用、依存検証、ネットワークなしのパッケージ試験は[開発用の再現手順](../../docs/managed-backend-build.md)を参照。導入・画面検証の残条件は[設計記録](../../docs/traffic-blob-design.ja.md)を参照。コンパイル成功をVM・画面の合格とは扱わない。

既存のJWT認証、ディレクトリFD基準のファイル参照、明示的なデータ所有を維持する。ホスト共有、Dockerソケット、既存データのマウント、外部スキャン、クラウドモデル呼び出しは追加しない。
