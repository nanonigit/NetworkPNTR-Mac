# New LLM profile provider menu

The frozen ARTEX browser opens an empty new-profile form with a wire-format
picker, endpoint, key, explicit model discovery, connection test and save.
Keep that form available as Custom configuration. Add OpenAI, Anthropic,
Gemini and Groq as named starting points in the Mac New Profile menu. The
provider is chosen before the form opens and before credentials can be
entered. Saved profiles open through their existing edit action.

The Lazyweb desktop results for V7 and Vercel describe separate provider and
credential actions and compact provider selection. Use the native menu
control and the existing editor. The frozen browser remains the reference
for all shared form operations. The provider shortcuts are a Mac extension.

Each choice creates a fresh draft through the existing preset constructor.
Model discovery and save still require the user's explicit action. Brand
names are shared across English and Japanese, and the custom choice uses
the bilingual catalog. Test preset isolation and custom defaults, render
both editor languages offscreen, and check keyboard and VoiceOver on the
running app before accepting the screen.
