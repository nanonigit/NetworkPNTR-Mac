# Linux client for the cloud egress socket

The managed backend enables the vsock transport only with `ARTEX_MAC_CLOUD_EGRESS=vsock-v1`. An unset mode keeps the existing transport. An unknown nonempty mode, a custom proxy or a custom session header fails closed in this mode. Model discovery and provider completions use the same switch. This phase compiles the client and leaves guest init activation for a signed VM proof.

Select an operation from the exact HTTPS host, port, method and path. Reject URL user information, escaped paths, queries, fragments and Host overrides. Send only the expected key, stream flag and bounded body to host CID 2 and port 8790. The fd is nonblocking, close-on-exec and deadline-bound. Cancellation closes the owned file without a direct-IP fallback.

Response bodies are incremental. Only the explicit end frame becomes EOF. A transport failure after a complete JSON body or OpenAI's SSE DONE marker still fails. The managed SDK drains the broker stream after DONE, and model discovery checks read errors. No broker control fields are conveyed as provider HTTP headers.

After any request bytes may have reached the broker, a framing or I/O failure carries an outcome-unknown marker through Go's wrapped errors. The SDK, task router and worker retry classifier reject replay. Status-based retries require a completed broker response, including non-200 responses and the quota capture path.
