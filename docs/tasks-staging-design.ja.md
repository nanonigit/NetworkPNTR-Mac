# T5 — タスク作成前の添付通信

固定ブラウザtasks/page.tsxは下書きUUIDを保持し、POST /api/chat/upload?scope=staging&id=<draft>へfileを繰り返すmultipartを送信します。chatupload.goはリクエスト全体128MiB上限、同名保存を改名しname/path/size/absを返し、drafts/<id>/uploadsへ保存します。ネイティブのデータルートは/state/app/dataです。参照UIはアップロード中の作成を無効化。失敗時に一部保存の可能性があるため自動再試行/ロールバック成功とはしません。

この段階は通信を実装し、会話添付を維持します。UUIDだけを受け取る専用capabilityを追加し、任意scope/path/queryを許可しません。既存のmultipart上限/ファイル同一性/ソケット所有/期限/取消と認証世代/進捗ゲートを共有します。機能層にBearer入力は設けず、ホスト実行/RPC/共有/NIC/新HTTPサーバーは追加しません。

上限付きの200JSONを生バイトから直接decode。既存の名前/サイズ検証、uploads/nameと/state/app/data/drafts/<小文字UUID>/uploads/nameのUTF8完全一致、非空/選択件数一致/バイト単位重複なしを必須にします。abs欠落/別下書き/不正/巨大/200以外を拒否。Unicode正規化やホストURL変換は禁止。サーバーの衝突改名は保持し、選択元の名前との一致は求めません。認証世代/取消確認後だけ結果を返し、不確実な失敗は自動再試行しません。

ヘッダ/認証、UTF8/BOM/NFC/NFD、別文脈/トラバーサル/制御文字、空/部分/重複/サイズ/状態、期限切れ/旧認証/取消/進捗をTDDで試験。模擬通信と一時通常ファイルを使い、既存認証/multipartも回帰確認。レビュー/全体試験/署名/日英記録へ進みます。モデルの下書き所有、UI選択/進捗/操作ガード、説明への日英一覧、実VM/ブラウザ比較は後続の必須条件。通信層だけで機能全体を合格にしません。UI変更なしでLazyweb対象外です。
