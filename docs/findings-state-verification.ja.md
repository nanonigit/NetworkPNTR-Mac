# F2 Findings状態基盤の検証

F1上に観測可能な読取/ページ/保持状態、捕捉した編集/削除結果、独立更新ループを実装。平坦20/グループ10の既定値、展開タスクごとのページ、全体統計、UTF8単位の条件/資産、文脈付き詳細、ページ間の出力選択を固定ブラウザの状態契約に合わせた。範囲外ページは桁溢れしない補正読取を1回だけ行い、失敗時は最終成功値/古さ/安全なエラーを保持。await前に条件を捕捉し、古い応答と後始末が新しい取得を上書きしない。平坦/グループと統計は独立した5秒更新。資産表示は1回のスナップショットで、変更ゲートに止められた初回取得は実際の所有試行完了まで保持する。画面や実VM/バックエンド操作は追加せず、Lazyweb対象外。

編集/削除には捕捉した表示所有権と表示/詳細の変更可能な独立ハンドルが必要。ワークスペース単一変更ゲートは停止/リセットでも終端まで保持。ローカル検査/事前取消は未送信。固定版の複合PATCHは非原子的なので、サービス引渡し後のHTTP4xxを含む全失敗を不明扱いとする。照合した確定応答だけで既知キャッシュを更新し、継承/文脈詳細は文脈付き再取得まで古い状態で保持。確定削除は対象の行/選択/詳細だけ除く。後の取得失敗で変更確定を消さない。不明IDは捕捉した発生回リビジョンとセッションによる明示確認まで変更を止め、読取成功でも解除しない。同一セッションの停止後完了は不明IDを保持し、リセットは旧表示を破棄するが保留書込みを早期解除しない。自動再送なし。
