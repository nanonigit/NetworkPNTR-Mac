# 英語・日本語の言語ゲート

ユーザー指定: 最終アプリはen/jaのみ。現状は初期監査で、実装合格ではない。比較ブラウザはe75ae371ad777ffd1eecdd28d2781a6519b05591のまま固定する。

| 発見 | 根拠 | 必要な対応 |
|---|---|---|
| ネイティブは日本語直書き中心、機能名は英語混在 | Sources/ArtexMac、A6/A7の実画面 | カタログ化して日英両方・読み上げを確認 |
| Autoの既定説明が中国語 | 固定db/db.go:212、両画面AX | 組み込み既定値だけ表示を翻訳し、編集済み説明を保持 |
| 新規会話の既定名が韓国語 | 固定server/conversations.go:56、A7両画面 | 既定表示・新規生成を対応し、独自名と元データを保持 |
| 終了サマリーが中国語、エラー接頭辞が韓国語 | A6保存本文の実画面・AX | backendシステムテンプレート・生成言語指示を監査。過去のモデル／ユーザー内容とは区別 |
| backendは5言語対応、不明値が韓国語になる経路 | server/errmsg_i18n.go、errmsg_catalog.go、server.go:3405/3536 | 切替は日英だけにし認証付きoutput_languageと同期。非対応の既存保存値も試験 |
| guest起動はARTEX_LANG=ja固定 | guest/backend-init:75 | 検証済みの選択値と永続・再起動確認 |
| ChatServiceに中国語・韓国語の完全一致判定あり | 未設定エラーallowlist | 内部比較データは未翻訳UIではない。表示する静的案内を選択言語に合わせる |

| タスク・資産の自動関連説明が中国語 | 固定db/schema.sql:667-683のsync_task_asset_links。F4aでは33件のsystem関連を生成 | 表示時に既知のシステム既定文言を英日化し、比較版の生データと独自の説明は保持。実表示の受入は未完了 |

受入条件: 全21機能と移植済みの各状態を日英で確認。初回、双方向切替、再起動、既存データ、アクセシビリティ名・ヘルプ、確認画面・メニュー・エラー、初期エージェント名、空・読込表示、新しいシステムメッセージを含む。翻訳欠落は英語フォールバック。ソース検索だけでなく実際のAX・画像で確認する。製品所有の表示にはハングルを残さず、中国語は既知文言・出典で識別する。漢字全体の禁止やCJK削除はしない。ユーザー内容・独自名・取込内容・過去履歴・モデル引用の破壊的翻訳は対象外。ユーザーが別言語で回答を求めることは妨げない。

初期監査時点では切替・カタログ・backend同期が未実装で、このゲートは未完了でした。現状の失敗証拠と比較ソースを保持し、翻訳済みブラウザへ黙って差し替えない。


F3.2時点では英日切替と共通カタログを実装し、Findingsは61キーをパッケージで検証しています。全21機能・backendの生成文・実画面の言語受入は未完了です。F4aのソース監査で、source=systemのトリガー既定文言 `任务执行期间自动关联` を発見しました。利用者入力とは区別できる生成文言です。固定版と検証データは変更せず、タスク・資産の由来を移植する際に表示を英日化し、独自に編集した説明の保持も検証します。SQL・ソース確認だけで実表示を合格とはしません。
