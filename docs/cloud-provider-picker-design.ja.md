# LLM 新規プロファイルのプロバイダーメニュー

固定ブラウザ版は新規作成で空のフォームを開き、通信形式、接続先、API キー、
モデル取得、接続テスト、保存を扱う。Mac でも「カスタム設定」からこのフォームを
開けるようにする。新規作成メニューに OpenAI、Anthropic、Gemini、Groq を追加し、
キー入力より先にプロバイダーを選ぶ。保存済みプロファイルは従来の編集操作で開く。

Lazyweb の V7・Vercel のデスクトップ画面メタデータを参考に、選択はネイティブの
メニューにまとめ、キー入力は既存のフォームに置く。共通操作の比較基準は固定
ブラウザ版であり、4社へのショートカットは Mac 版の追加機能とする。

既存のプリセット初期化を使い、選択ごとに新規の下書きを作る。モデル取得と保存は
利用者の操作で行う。ブランド名は日英共通で、カスタム設定は日英カタログから表示する。
下書きの分離とカスタム初期値を試験し、日英のフォームをオフスクリーンで構築する。
キーボードと VoiceOver は実画面で確認する。
