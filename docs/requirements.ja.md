# 要件と完成ゴール

外部タスクworkspaceは実handoff時に捕捉contextとlive/cold処理枠を照合し、未送信取消と送信後不明を分ける。既存レイアウトと送信後確定は保持する。task-external-handoff-design.ja.md参照。

タスク直接書込とcategory/archive/bulk処理枠取得は、送信/token付与前に取消/activity/lifetimeを照合する。送信後不明とresetの終了待ちを維持する。task-mutation-handoff-design.ja.md参照。

既存FindingStoreの編集/削除も取消確認済みのtransport handoffを必要とする。部分PATCHの不明とresetでゲートを保持する仕様は変えない。findings-mutation-handoff-design.ja.md参照。

F5b状態は一覧/詳細/本文ページと捕捉した書込の所有権を選択・停止/再開/resetをまたいで保持し、同じ不明回の明示確認まで再送を禁止する。後の読取は過去の保存を証明しない。findings-traffic-state-design.ja.md参照。通信への引渡し前の取消/停止は結果不明にしない。

F5bは捕捉したowner/context/snapshotによる証跡追加/編集/削除/順序、versionと正確な本文、自動再送禁止を必要とする。保存後の読戻し失敗も結果不明として扱う。書込能力の後に状態の所有権/不明処理と実guest/画面検証が必要。

F5は固定版の証跡閲覧/変更/本文保存、lineage、再検証/deepen、report、全出力範囲/形式まで必要。F5aの読取契約はその第一段階であり完成範囲を狭めない。表示文字列と本文のバイトoffsetを分離し、owner/contextと未知のユーザー内容を保持する。findings-advanced-design.ja.md参照。

別の非公開リポジトリnanonigit/networkpntr-macとして、ネイティブMacアプリを作る。このApple Silicon Macで、ブラウザ・Docker Desktop・ターミナル・手動のサーバー起動なしに利用できる。画面はSwiftUI、AIのコマンド実行とDBはアプリ管理のLinux VM内に置く。

## 完成条件

R1. ブラウザ版の主要21機能、全画面・詳細画面・操作を機能対応表へ記載し、機能を黙って省略しない。外観だけでなく一連の操作の同等性が必要。
R2. e75ae371ad777ffd1eecdd28d2781a6519b05591を比較基準に固定。同じ入力・データで、入力検証、エラー、空状態、進捗、キャンセル、更新、出力、再起動後の保存を比較する。APIテストと画面操作の証拠を分けて残す。
R3. Features/Systemの階層、項目名・順序、タスクと詳細の関係を踏襲する。Macのメニュー・キーボード・ウィンドウに合わせた変更は理由と比較テストを記録する。Lazywebは補助資料、ブラウザ版を主基準とする。
R4. AIからのホスト上のシェル実行、Dockerソケット、ホスト共有フォルダ、任意ホストRPCを禁止。初期VMはネットワークなし。後で明示的な接続先ポリシーを設計する。キーをログ・Gitに保存しない。
R5. 起動・停止・再起動、クラッシュ、容量不足、更新失敗と復旧を検証する。データは専用ゲストディスクに保存。現在のブラウザ版は別環境として保存し、移行は検証済みの明示的インポートで行う。
R6. ローカル起動できる.appを作る。配布署名・公証・初期Macでの導入・ライセンス・復元検証は最終段階の必須条件。まずApple Silicon/macOS 15以降を対象とし、Intel対応は未実装と明記する。
R7. AIの結果や進捗を捏造しない。VMの起動状態・ゲスト起動確認・API起動完了は区別する。APIが通るだけでネイティブ画面を完成扱いにしない。

最初の到達点はフェーズ0の設計文書とフェーズ1のVM技術実証。以降も全体ゴールとして残し、モック画面やWebViewだけで全体完了にしない。

A3全内容照合の追加要件: 約128MiBの実添付を認証付きvsock経由で全バイト取得し、一定量のメモリでハッシュ照合する。通常JSONの4MiB制限、認証世代、取消/VM停止時の記述子所有権、固定ブラウザを維持。期待サイズとHTTPフレーミングの完全一致を要求し、不完全・超過・圧縮・曖昧な応答を拒否する。これは受信内容の証明であり、同時書換えに対するファイルスナップショット保証ではない。添付UIとダウンロード/書出し操作全体は別の未完了ゲート。

添付の進捗/取消追加要件: 実際にソケットへ書いたmultipart本文のバイト数を単調増加で通知し、認証情報/HTTPヘッダー/ホストパスを含めない。通知頻度を制限し、本文送信完了とサーバー保存成功を区別する。Task取消、VM停止、ログアウト/再ログイン後の古い応答・進捗を採用しない。実VZで1MiB以上の本文転送中の取消/停止をソケット単体テストと別に確認し、再起動後は所有する部分ファイルだけを確認・清掃する。

A4添付下書き要件: name/path/sizeを保持し、任意のゲストabsは表示/送信モデルから除外。uploads/単一basenameと非負の128MiB以下のサイズを検証。本文なし+添付ありの送信を許可し、両方なしは通信前に拒否。会話別所有権とstop/resetの世代を守る。ブラウザ同様の送信時クリア/失敗時復元を行い、新しい編集/添付を古い応答で上書きしない。カード除去はローカル下書きだけでゲストを削除しない。ファイル名/パスはUnicode正規等価性でなくUTF8バイトで識別する。会話作成/アップロード引継ぎとpicker/cardsの検証は後続必須ゲート。

A4.2転送所有権: feature側はJWT/任意経路を受け取らない認証済み型付きAPIを使う。空選択/非対応能力は会話作成前に拒否。新規は一度だけ会話を作成、既存は直接そのIDへ送る。本文と型付きカードを保持し、選択変更後も元の所有会話へだけ結果を保存して選択を奪わない。起点/対象ごとに重複を防ぎ、取消/stop/reset/削除で古い結果や進捗の復活を防ぐ。削除失敗では従来の下書きを保持。取り消したからといって受理済みゲストファイルを暗黙削除しない。picker/cards/UIと全体同等性は後続ゲート。


チャット送信の空判定・送信本文・失敗時の復元は固定ブラウザのECMAScript trimに合わせる。新しい編集の保持と添付のみ送信を維持する。Serviceは渡された本文のバイトを保持し、空判定だけ同じ空白集合を使う。UIの判定はA5の別条件。


A5添付UI: 対象ウィンドウの複数ファイル選択パネルを使い、ディレクトリ・パッケージを除外。選択取消では会話を作らない。ファイル名・サイズ・ローカル削除・進捗・安全なエラーを表示。読み取り権限は転送の成功・エラー・取消まで保持して解放し、画面離脱でパネルと所有タスクを取消。古い選択結果を別会話へアップロードしない。共有ECMAScript判定で添付のみ送信を許可し、処理・履歴読み込み・転送・実行中は送信不可。合成した使い捨てファイルで固定ブラウザと実操作を比較し、実プロバイダーの認証情報は使わない。


A6送信済みユーザーメッセージ: inlineまたは遅延取得したDetailのJSON {text, attachments}から、全文の通常テキストと名前/相対パス/サイズの読取専用カードを固定UserRowに合わせて表示。画面に現れるユーザー行のみ取得し、空応答/失敗は要約を保持、安全なエラーと再試行を表示。取消・画面離脱・更新・別会話への古い応答は反映しない。メタデータを検証してabsを無視し、不正な添付は本文をそのまま表示。ファイルを開く/削除/ダウンロードやホストRPCは追加しない。構造化/通常/空/失敗/Unicodeを固定ソースと実ブラウザ/Macで比較する。


A7復元比較要件: 使い捨てMac版と固定ブラウザを、再起動前後ともLLMプロファイル0件で揃える。実ピッカーで添付し、本文＋添付／添付のみの送信503後に元の入力・カードが戻り、保存ファイルを保持し、user activityを作らないこと。専用モードは競合するseedフラグをVM起動前に拒否。製品UI・ネットワークの変更なし。


A7エラー訂正: 既知のLLM未設定の送信503は、DB障害と断定せず静的なLLM設定案内を表示する。固定カタログの完全一致だけを変換し、未知・不正・追記付きの本文は表示しない。他のルート・ステータスの挙動は維持。


R8. 最終的なアプリの対応言語は英語(en)・日本語(ja)のみ。明示的な切り替えを永続化し、ナビゲーション、操作、アクセシビリティ、検証・エラー、組み込み初期名称・説明、新規バックエンドシステム文言に適用する。初回・双方向切替・再起動・既存guest状態・フォールバックを検証。どちらでもアプリ所有の中国語・韓国語を残さない。ユーザー入力、取込文書、既存会話履歴、コード、モデルの引用、独自名称を翻訳して監査を通すことはしない。固定ブラウザは更新せず、日英限定の意図した相違を明記。


L1言語基盤: 公開型はen/jaだけ。新規時はOSの優先順で最初の対応言語を選び、それ以外は英語。明示選択は後のOS言語変更に影響されず保持。不正値・文字列でない保存値は英語へ正規化。無関係な設定を保持し、クラウド・backend認証情報は保存しない。このCore段階はUI追加ではなく、単独ではR8を満たさない。


L2共通画面ゲート: 常時使えるネイティブ選択にEnglish/日本語だけを表示。共有ナビ・機能名・Rootの未利用／詳細文言を日英リソースへ移す。切替でruntime・認証・Chatの同一性、入力・添付・選択を保持。コンパイル済みカタログを署名アプリへ同梱。ホスト言語と無関係に両言語を取得し、日本語欠落は英語へフォールバック。この段階だけで機能内部／backend翻訳を完了としない。


L3 Chat操作: 一覧・ヘッダ・入力、添付操作・進捗・ネイティブ選択、履歴の空／読込／詳細操作と引用操作を日英化。切替で本文・カーソル・IME・選択ID・非同期世代・ファイルを保持。既知agentキーかつ固定のAuto/pentest初期名称・説明とバイト完全一致するものだけ翻訳し、編集済み／未知内容を保持。既存会話名は来歴付きの新規名称処理まで元データを維持。Coreエラーとbackend同期は別ゲート。

L4aエラー基盤：ネイティブの静的検証文字列をBackendValidation型に移し、日英エラープレゼンターを追加。store移行中は従来の日本語LocalizedError互換を保持。明示言語で取得しOS設定に依存せず、未知のエラーを文字列化しない。HTTP／Keychain数値のみ埋め込み、任意のserver本文・パス・秘密を表示しない。この基盤だけでUIエラー切替／R8を合格にしない。

L4b Chatエラー：storeは安全な型付きAppErrorMessageを保持し、viewの現在localeで表示。view再作成・リクエスト発行・本文／添付／選択変更をしない。診断／旧試験向け日本語Stringは計算プロパティで互換保持。一覧／履歴／送信／停止／workspace／添付／部分削除／引用ページング／本文／詳細を対象とし、キャンセル・世代・所有者判定を維持。未知のエラーはraw情報を保持せず型付きfallbackへ縮退。store RED/GREEN・全試験・レビュー・署名・実native/browser失敗送信中の言語比較を別ゲートとする。Lazyweb検索chat error retry messageは隣接DoorDashメタデータのみ（類似度.385）で視覚証拠とせず、固定版のエラーUIを基準にする。

L4c移植済み画面のエラー／通知ゲート：AuthenticationSession・LLMStore・DashboardLoadStateはAppErrorMessageを保持し、日本語Stringは計算プロパティで互換。LLM完了通知はカタログキーで保持し、再取得失敗と独立させる。認証・LLM設定／編集／rotation・dashboardの現在view localeで表示。localeによる認証／変更操作／poll再起動やパスワード／APIキー保存をしない。フォーム・規約同意・世代・前回データを保持。周辺未翻訳操作／規約言語は別ゲート。検証失敗・未知エラー秘密除去・保存成功後の再取得失敗・dashboard前回データ保持を試験。Lazyweb settings inline validation errorは隣接Gopuff captchaメタデータのみ（.356）で視覚証拠としない。実native/browser比較はMac解除まで延期。

L5認証／規約：ネイティブ認証ラベルを型付きカタログで日英化。AuthTerms.loadAllで固定規約の両言語を一度読み込み、既存シートの現在localeで表示。パスワード／確認／同意／focusのbinding・task同一性・送信・phase変化時の消去を保持。読了は固定browser同様、シートを開くたびリセットし、表示中の言語変更ではreadToEndを保持。言語に基づくview再作成なし。各言語28項目のauth.terms全文が固定参照と一致し、規約改変や実行時ネットワーク取得なし。自動setup-token／固定ユーザー名の案内はnativeの実動作に合わせる。resource/API RED/GREEN・レビュー／全試験／署名同梱を確認し、実native/browserの操作／scroll／読了はMac解除まで未完了。Lazyweb terms agreement modalはPostman隣接メタデータのみ（.479）で画像証拠にはしない。

L5隣接読了判定修正：初期の空スクロール領域で、規約読み込み前に読了を付与しない。シート内の読了状態を型で保持し、Equatableなviewport観測にdocumentLoadedも含める。短文でatEndがtrueのままでも読込完了を別イベントとして扱う。失敗／空文書は同意ボタンを有効化せず、読込済み文書の末尾で読了を保持し、表示中の言語変更では維持、新規シートは未読。ログイン権限強化ではなく読了UIの修正で、独立した同意checkboxは変更しない。別RED/GREENと実scroll比較待ち。
