## Five Whys

1. Why did legacy uppercase hash downloads fail? The managed replacement bypassed normalization.
2. Why was the opener strict? Stored metadata requires canonical lowercase hashes.
3. Why were these contracts conflated? A file-security helper replaced a public compatibility wrapper.
4. Why did initial HTTP tests miss it? They used canonical hashes generated by the new metadata endpoint.
5. Why keep normalization at the wrapper? It preserves existing request semantics while the internal opener and stored association remain strict. Test both boundaries independently.
