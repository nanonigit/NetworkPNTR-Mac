# ネイティブ添付UIの調査

## 範囲と根拠

A5は既存の型付きアップロード処理をネイティブUIへ接続する。実装前に要件・設計・タスクを記録した。Lazywebの補助事例は https://www.lazyweb.com/agentic-search/38aa7a86-3a2a-4af4-836a-fabad477eca1 、動作基準は固定ブラウザのComposer。Claude入力欄は目視、別画像は空白のままで視覚的根拠にしない。アクセシビリティは https://raw.githubusercontent.com/addyosmani/web-quality-skills/main/skills/accessibility/SKILL.md をネイティブのラベル・キー・フォーカスへ適用。実VoiceOverは未完了。

RED0f6d656/GREENd53c889で7テストと操作部品を追加。REDf21701b/GREENfeee382で転送開始時の会話確認、56fc85eで正しい会話への転送・権限寿命を統合テスト。レビューで古い取消が同じ会話の新しい転送を止める問題を発見し、RED665b427/GREEN4610e3bで処理IDを照合する。ライフサイクル・削除の一括取消は維持。実際の容量超過選択でローカルエラーが通信エラーとして表示され、RED94c4127の5失敗からGREENba85afbで固定文言のChatUploadBodyErrorだけを表示。未知の例外は一般化を維持。両修正は別レビュー済み。

## 原因・再発防止

所有権の5 Whys: コールバックが別処理へ作用→会話切替・Task開始・処理置換は非同期→表示の会話IDのみで判定→UI境界へ処理IDを渡していない→Coreの所有権テストだけでUIの古いイベントを検証していない。対策: 元会話を固定し開始時にも確認、削除も元会話へ固定、取消はUUID照合、パネル完了トークンを無効化し回帰テスト。

エラー文の5 Whys: 容量エラーが通信エラーに見える→WorkspaceはBackendAPIErrorしか認識しない→ファイル検証は別enum→安全な一般化で対処可能な説明まで隠れた→層をまたぐ表示テスト不足。対策: 固定文言enumのみ許可し、任意例外のパス等は出さない。Fishbone: 非同期イベントの所有権、パネル寿命、例外型の境界、統合例不足。Timeline: 設計→RED/GREEN→所有権修正→レビューで古い取消→UUID修正→実操作→容量表示の失敗→5例の修正→新しい署名アプリで再検証→全テストと範囲を限定したカバレッジ。

## 実操作

未昇格のソースカーネルを使う署名付き計測アプリ2回で、通常の診断・一時Keychain削除・VMの協調停止が完了。V1では実ウィンドウの選択取消で会話が作られず、合成2ファイル（NFDのeアキュート名51B・empty.txt0B）と入力本文がカードへ引き継がれ、ローカル解除も動いた。添付のみ送信は受理され、その後ゼロNICのVMで予約ドメインapi.example.invalidのダミー設定に対するmodel_errorとなった。送信後の添付メタデータは履歴に未描画で、リッチ表示の条件に残す。

使い捨て固定ブラウザでは同じ名前・サイズ・本文、LLM設定なしの失敗後カード復元、1カードの解除を確認。認証付き読取で両ファイル・ハッシュが残り、拒否された履歴は空だった。MacのV1にはダミー設定が残りブラウザは設定なしなので、送信失敗の同一条件比較として合格にしない。ブラウザの選択取消はドライバーが1ファイル必須で未検証。外側の比較待機は観測後にタイムアウトし資源を片付けたが、比較ハーネス全体の成功とはしない。最初のinternalネットワークだけのポート公開は接続不可だったため、別frontendネットワークのループバック入口を使った。ARTEX/DBはinternal、普段の8787は変更なし。

V2では128MiBの入力ファイルを転送前に拒否し、修正した具体的な容量説明を実画面で確認。127MiBでは進捗を表示。最初の取消は間に合わず、次は新しいAXに基づき約54.05%（68.6MB/127.0MB）でクリックでき、進捗が消え既存カードだけ残った。3回目は116.5MB/127.0MBの画像を保存できたが、その後の取消操作がelementHasNoFrameで失敗して転送が完了した。別の取消成功や見た目の受入に数えない。保存画像ではバーが速い数値更新より遅れて見えるため、同期・アニメーション/動きを減らす設定・静止時の挙動を要確認。カード・解除・容量表示の修正前後は画像あり。
