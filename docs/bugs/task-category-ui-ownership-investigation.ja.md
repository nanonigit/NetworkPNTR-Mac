# T10 カテゴリ画面の所有権・互換性調査

収集・再現: 実ウィンドウ・VM・利用者データを使わない試験で、用途が異なる画面終了通知、同名カテゴリの重複作成、初期分類の早すぎる決定、既存選択のキャンセル確認漏れを確認。比較元は固定 e75ae371 の管理とカテゴリ選択。Getter は別用途を隠しても Setter が同じ ID を閉じる問題を01c7664で2件失敗として保持。既存8を選ばず POST して10を選ぶ差を2b565ce、空の環境でも未分類を選びタスク応答前に決定する差を4ba1e25で再現。キャンセル済み操作の結果と通知数も試験履歴に残す。

5 Whys: 読み取り側だけで用途を確認し書き込み側が不足、共有画面は ID と用途の両方が必要、ローカル選択の近道が従来の送信ゲート内のキャンセル確認を迂回、分類応答完了をタスク応答完了と取り違え、初期試験では別順序と通信しない経路の検証が不足。Fishbone はライフサイクル（画面・用途・リセット）、実行順序（Task・キャンセル・並列応答）、データ（空・新規・未分類）、互換性（既存名）、試験境界に整理。

修正: 画面終了は固定 UUID と用途を照合。親操作・ファイル選択を保護。JS trim と小文字化後のバイト列で既存名を照合し、NFC 同一視や POST を行わない。キャンセルはローカル選択と通信の前で確認。初期分類は両応答後に選び、固定した編集 UUID が変わった場合や入力・明示選択を上書きしない。画面開始で古い背景読み込みを無効化。カテゴリ専用の読み取り世代により会社・モデル・テンプレート・参照タスクの取得は中断しない。TaskStore の共通変更ゲートは同時操作を防ぎ、セッション終了でも処理完了まで保持。

再発防止: 用途と所有者が古い Binding、背景読み込み中の画面開始、応答順序、明示選択、親本文・UUID・選択保護、他選択肢の並行読み込み、同名の既存選択とキャンセル、部分成功・全件失敗、共通ゲート、送信前後のリセット、結果不明保持を通常 CI に含める。画面外構築から実 OS のキー操作・ドラッグ・終了通知や永続化を推定しない。実ブラウザ/ネイティブ/VM 比較は解除後に必要。

CI 追記: 5e124ae の40258111107は「closure captures name before it is declared」でコンパイル失敗。ローカルSwift6.4は受け入れたが、CIでは後続の同名ローカル変数との曖昧な参照を拒否した。同名選択のクロージャを self.name と明示し、操作用スナップショットを selected/submittedName に改名。処理・キャンセル・ツールチェーンを変えず、入力固定を保つ。全体405件（成功404・既存AX1件スキップ）を再実行し差分レビュー済み。CI互換性は新しい実行で確認する。変更なしの再実行で失敗履歴を消さない。
