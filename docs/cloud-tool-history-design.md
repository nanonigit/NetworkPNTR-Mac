# Managed cloud tool history contract

CP2 extends the pinned norma v0.4.3 dependency in the managed build only. Never edit the fixed browser, Go module cache or upstream account. Apply a checked patch to a writable copy of the verified module, then replace that module only inside the build container. The normal staged guest is not promoted by this work.

Reproduction uses actual agent.ConfigFrom/NewProvider Stream and Complete through loopback HTTP, two tool calls, synthetic signatures/results, normalized JSON save/reload, then a second request. No tool executes. Current code loses signatures in both modes and misassigns interleaved stream inputs to the latest tool. The test is an actual runtime RED, not an inferred missing-field report.

Design: store a typed `OpenAIThoughtSignature` on tool content blocks with an explicit JSON history key. Parse only `extra_content.google.thought_signature`, treating it as opaque text, and replay only that known field on the corresponding OpenAI tool call. Do not preserve arbitrary provider-controlled fields or invent bypass signatures. Add explicit optional tool indexes to normalized events; accumulate tool input/signature by index while preserving legacy unindexed Anthropic events. Retain early signature events until their matching start, without applying them to a different tool. Strip the OpenAI-only history field recursively from Anthropic requests on copies, preserving original history and Anthropic thinking signatures. This is not a general cross-provider history migration or a capability grant.

Validate stream and non-stream signed/unsigned round trips, interleaved inputs, seven-byte flushed network writes, early/late metadata, normalized JSON persistence, no unsigned metadata insertion, and Anthropic field isolation/no input mutation. Run all pinned llm tests and managed agent/server tests in Linux with no external network during tests. Build the managed backend with the checked dependency patch, record source/module/patch/image hashes, and keep default guest promotion separate. Actual task transcript/DB/restart/compaction, four-provider cloud egress, errors/usage/cancel and live UI/browser acceptance remain open.

Schema source: [Google thought-signature OpenAI examples](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/thinking/thought-signatures). These document the tool-call `extra_content.google.thought_signature` shape; testing this shape does not establish Vertex AI support or Developer API model availability.

Review refinement: bind each stored signature to a SHA-256 context derived from the runtime-resolved OpenAI base URL and model (no key or raw URL in the history field). The decoder stamps it, normalized JSON retains it, and request encoding copies and removes signatures with an absent/different context. An unbound imported signature is never trusted for replay. Scope metadata itself never goes upstream; Anthropic stripping removes both signature and scope recursively. This prevents accidental cross-endpoint/model forwarding, not malicious history forgery or general credential authorization. Same-origin key rotation/history migration remains a separate lifecycle contract.
