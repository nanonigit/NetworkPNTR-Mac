# Indexed tool execution and process restart

The pinned ChatAgent uses a file-backed norma transcript for model context and a separate PostgreSQL activity store for display. A process-level fixture exercises the real agent and HTTP provider with the same transcript directory across two independent Linux processes. The provider issues exactly one fixed Read of a temporary witness file, accepts its result only with the exact call ID, arguments and signature, then requires the same history after the first process exits and the file is deleted. Both streaming and non-streaming must complete. The resumed process must execute zero tools and append a final reply to the existing transcript. The mock binds to loopback in a network-disabled build and the child verifies the exact fixture URL shape.

The new signature event exposes an execution bug. The harness finalizes its separate sequential tool buffer on every event other than an argument delta. A signature before arguments therefore executes an empty Read even while the history accumulator retains the correct arguments. Interleaved indexed calls have the same split between execution and stored history. For indexed calls, defer dispatch until the stream has a terminal event and a tool-use or end-turn stop reason. Dispatch the exact completed blocks from the existing accumulator in tool-start order. Keep the scheduling of unindexed tools and normal text streaming. A stream error or incomplete indexed completion must leave buffered calls unexecuted. The existing tool executor retains permission checks and concurrency policy.

Maintain a separate checked patch to pinned norma v0.4.3 in the managed builder. Run the actual ChatAgent process fixture, harness regressions for interleaved inputs and interrupted streams, and the full related packages under network isolation. Build a Linux backend candidate with a new version. The process fixture establishes transcript reload and tool replay behavior. The dedicated VM, normal chat API and persistent state disk across a VM reboot remain the next acceptance gate.

Review refinements require all raw indexed inputs and IDs to pass validation before any indexed tool-use event. Early argument fragments attach to the matching start. An unmatched fragment rejects the completion. The consumer accepts the entire batch before it enters the executor. Queue processing and semaphore waits use the captured tool context for that turn. The tool call rechecks it after permission hooks. An already emitted interruption result remains authoritative if a worker finishes later.
