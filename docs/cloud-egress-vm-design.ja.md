# クラウド中継の実機検証

固定した Linux 候補を専用の新規データディスクで起動し、中継の実装と同じ
virtio ソケット、要求パーサー、応答フレーマーを使う。認証済みアプリ API で
OpenAI、Gemini、Groq のモデル一覧とチャットのストリーミングを確認する。
デバッグ専用の模擬 API が合成キー、経路、本文を検査し、分割した HTTP 応答を返す。
外部通信は行わない。OpenAI の応答を保留した状態で VM を停止し、要求の中断を確認する。
停止後にゲストの通信インターフェースがループバックのみで、共有マウントがなく、
ログに資格情報が残っていないことを確認する。
