# ログイン不要のネイティブ起動

## 要件（2026-11-18のユーザー変更）

通常起動でアプリ用アカウント作成、パスワード設定、ログイン、ログアウトを求めない。従来のネイティブ認証画面の要件を置き換え、NetworkISPR Mac・RepoAUDT Macと同じ直接起動にする。VMの既存データ・プロバイダーキー・タスク履歴を保持し、独立した固定ブラウザ環境は変更しない。ゲストAPIのJWT、認証付きvsock、ホスト共有・NICなし、MCPの明示許可と所有世代の検証は維持する。エラーは再試行としパスワード画面へ戻さない。クラウドAPIキーの任意設定は別扱い。

## 設計

アプリは起動ごとに独立した256ビットの接続権限を生成し、既存の通信・セットアップ用秘密とは分けて、バージョン付きの専用シリアル初期化で渡す。`native-local-session-v1`を宣言した検証済みゲストだけで使う。固定ソースへの管理対象拡張に、ループバック限定・固定POSTの内部セッション経路を追加する。JSONの長さと項目を制限し、クエリ・Originを拒否、権限を定数時間で確認し、応答は保存不可とする。既存のJWT署名・保存ハッシュとの結び付けを再利用する。既存ハッシュは変更せず、新規DBだけに安全な乱数由来の内部ハッシュを原子的に保存する。利用者へID・パスワードを割り当てない。接続権限の環境変数はサーバー生成時に消費・削除し、ツールの子プロセスへ継承しない。設定なし・不正な権限では認証を省略せずトークンを発行しない。他のAPIのJWT保護は維持する。

通常版は資格情報をメモリ内だけに保持し、起動ごとに内部JWTを取得する。Keychain・プロバイダー設定・VMデータを削除しない。手動認証は固定ブラウザと比較する明示的DEBUG診断だけに残す。通常のサイドバーから「アカウント」を外し、ダッシュボードへ直接入る。接続中は進行状態、失敗時は再試行を表示する。通常の操作で設定・ログイン・ログアウト画面へ到達させない。内部セッションが無効になれば所有世代とMCP許可を失効させ、再接続にも利用者のパスワードを使わない。

固定Linux Goビルダー内だけで拡張を構築し、基準ソースは変更しない。検証済みゲストのrootfsへ適用し、カーネル・CPU・メモリ・パッケージ・API Recon方針を保つ。通常版とCloud Preview版を構築してハッシュへ結び付け、更新前の成果物を保持する。試験を通すためにカーネルを切り替えない。

UIの根拠：両兄弟アプリの起動ソースはアプリ内アカウントを挟まずネイティブRootViewを使う。Lazywebの上記英語検索ではLaunchNotes等のオンボーディング情報が得られたが、アカウント中心の画面は採用しない。既存シェルと簡潔な進行・再試行だけを使う。このログインUXはユーザー指定でブラウザ版から変更し、その他の機能・データ比較は継続する。

## 試験順序・受入

1. Goで権限なし・不正権限・外部接続元・Origin・クエリ・項目/本文制限・DB失敗を拒否。新規初期化、既存ハッシュ・データ保持、JWTと保護API、秘密の非記録を検証。
2. Swift/Pythonで旧初期化の互換性、新初期化の乱数分離・秘匿、成果物宣言、キャンセル・401・MCP失効、通常UIからの認証画面排除、再試行と日英を検証。
3. 隔離コンテナ内で構築し、実DB/APIの新規・既存・再起動・古い権限拒否を確認。失敗も保持し、SwiftPMを使う試験は逐次実行。
4. 署名済みの使い捨てVMで、資格情報を入力しない初回起動、操作、再起動・移行後の保持、MCP許可、通常画面の日英を確認。固定ブラウザは維持。
5. 通常/Cloud Previewの既存データと識別子、署名・ゲストを確認し、READMEと名称を更新して両アプリへ適用し、レビュー済み変更を`[skip ci]`で送る。実起動・移行を確認するまで完了とはしない。断続的なVM起動の安定性は別の未完条件。

## 現在の実装チェックポイント

ルートとバックエンド拡張のREADMEは、英語・日本語の相互リンク付きで、旧製品名を含みません。自動接続は署名済みアプリでの合格まで、明示的な開発用 `--local-session-diagnostics` フラグに限定します。両方のゲスト変更はカーネル・CPU・メモリ設定を維持してビルドしました。通常アプリと利用者データは置き換えていません。初回ビルドの後処理で、タグのない元ランタイムイメージ2件のキャッシュ参照が削除されましたが、元アプリ内のゲストファイルは保持しています。ビルダーはタグのない入力を永続的に固定し、元参照を確認したうえで所有する一時タグだけを `--no-prune` 付きで削除するよう修正しました。配布前に修正後のビルダーの制御試験を行います。実DB試験はスキップなしで合格しましたが、実際の本番HTTPルーターとネイティブVMでの確認は未完了です。

使い捨て署名済みアプリで、通常・クラウド版の新規接続と従来環境からの移行が通過しました（合計8回起動）。停止後の秘密・隔離ログ監査、設定・終了タスク・履歴保持も確認しました。実Dockerのタグ後処理も通過し、クラウド合成バイナリの情報を修正しました。実画面と通常アプリへの適用は未完了で、クラウド実通信は対照版・候補版とも上流状態未確認です。local-session-native-verification.ja.md と bugs/local-session-cloud-egress.ja.md を参照してください。
