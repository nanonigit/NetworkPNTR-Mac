# NetworkPNTR Macの名称と互換性

製品名はNetworkPNTR Mac、リポジトリ名は `networkpntr-mac` に統一します。PNTRはペネトレーション（侵入テスト）を意味します。Swiftモジュール、実行ファイル、画面表示、新設MCPツールも新しい名前を使います。

既存のアプリデータ、Keychainのサービス名、バンドル識別子は、ログイン情報・APIキー・専用VMディスクを維持するため旧識別子を保持します。これらは画面に表示する製品名ではありません。

固定済みゲストの通信マーカー、認証ユーザー名、バックエンド内のパスと環境変数、ビルド識別文字列、検証ハッシュ、上流の利用条件と過去の検証記録は元のバイト列を保持します。送受信双方を再構築・再検証せず変更すると、起動・認証・完全性検証が壊れます。出典とライセンスの記録も保持します。

ブラウザ版のリポジトリと固定した比較基準は別環境です。今回の改名で履歴と公開範囲は変更しません。今後の画面と製品説明はNetworkPNTR表記を使います。
