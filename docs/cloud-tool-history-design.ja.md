# 管理対象クラウドのツール履歴契約

CP2として固定norma v0.4.3を管理対象ビルドだけで拡張する。固定ブラウザ、Goモジュールキャッシュ、上流アカウントは編集しない。検証済みモジュールの書き込み可能なコピーへ検査済みパッチを適用し、ビルドコンテナ内だけで置換する。今回の作業で通常ゲストを昇格しない。

実際のagent.ConfigFrom／NewProviderのStream／CompleteとループバックHTTPで、2つのツール呼び出し、合成署名／結果、正規化JSON保存・復元、次の要求まで再現する。ツールは実行しない。現在は両方式で署名が失われ、交互に届くストリーム引数が最後のツールへ混入する。実行時REDであり、フィールドの静的な推測だけではない。

設計：ツールブロックに型付き `OpenAIThoughtSignature` と明示的な履歴JSON項目を持たせる。`extra_content.google.thought_signature` だけを不透明な文字列として保持し、対応するOpenAIツール呼び出しへ戻す。任意のベンダー項目や署名検証を回避する値は追加しない。正規化イベントへ任意のツール番号を追加し、引数と署名を番号ごとに集約する。従来の番号なしAnthropicイベントは維持。開始より前の署名は対応番号の開始まで保持し、別ツールへ付けない。Anthropic送信ではコピー上でOpenAI専用履歴項目を再帰的に除去し、元履歴とAnthropic思考署名は維持する。一般的なプロバイダー間の履歴移行や能力許可ではない。

ストリーム／非ストリーム、署名あり／なし、交互の引数、7バイトずつflushする通信、早い／遅いメタデータ、JSON履歴保持、署名の捏造がないこと、Anthropic項目分離と入力不変を検証する。固定llm全試験と管理対象agent／server試験をLinux内・試験中外部通信なしで実行。依存パッチを適用した管理対象本体をビルドし、ソース／モジュール／パッチ／イメージのハッシュを記録する。既定ゲスト昇格、実タスクDB履歴・再起動・圧縮、クラウド通信、エラー／使用量／キャンセル、実UI・ブラウザ受け入れは別途必要。

形式の出典は[Google公式の署名例](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/thinking/thought-signatures)。ツール項目の形式を検証するもので、Vertex AI対応やDeveloper APIのモデル提供を証明するものではない。
