# 証跡保存の実VM受入

固定ソースe75ae371ad777ffd1eecdd28d2781a6519b05591で、署名VM／認証を通る保存を実測する。既存ブラウザデータは維持。新規非公開ディスク、NIC／共有ゼロ。プロバイダー設定、実行待ちタスク、AI自動実行、外部通知を作らない。基盤試験なのでLazyweb対象外。画面受入は別条件。

R1：ゲスト内の認証済みcustom-tool試験経路から固定Pythonコードを実行。呼出元のSQL・パス・URL・サイズ・本文は受け付けない。seed／監査／本文コードを固定しハッシュ記録。既存finding／trafficを拒否し、終了済み指摘33件と9101の証跡2件を生成。本文は先頭FEFF・NFD・中国語・韓国語を含むUTF8、空リクエスト、5MiB+17と129MiB+17バイトのバイナリ。原文データであり翻訳漏れではない。保存先は/state/app/data/evidence固定。比較用コンテナは専用アダプターを使う。64KiB単位で生成・監査し、blobs/ハッシュ先頭/ハッシュ.binへ0600保存。リンク・異なる所有者・既存blobを拒否。SQLは固定定数、トランザクション前提条件、時間制限を使う。snapshotシリアライズ・長さ・ハッシュを上流に合わせ、環境／ファイル／SQL／監査の異常系から試験する。

R2：DEBUG専用nativeクライアントで応答上限、固定ID／サイズ／ハッシュ、固定スクリプト、AI非実行を確認。

R3：署名VMProbeで出力を排他的作成し、新規ディスクとメモリ／非公開ファイルだけの資格情報を使用。固定成果物、CPU、ネットワーク／共有ゼロ、新規認証、データ監査を確認。実一覧／マニフェスト経路から両側を認証保存し、独立ファイル検証、既存ファイル保護、ログアウト後拒否、停止／再起動後拒否、永続化、空／バイナリプレビューを試験。通信中キャンセルは実通信を観測し、事前キャンセルで代替しない。失敗試行と診断も保持し、所有VMを停止。間欠異常を成功まで再試行して記録から消さない。

R4：所有する使い捨て固定バックエンド／DBをnetwork-noneで使用し、同じ本文を独立ストリーム検証で取得。native／生成元と全バイト・ハッシュ比較。非公開ハーネスはimportで動くものがあるので先に内容確認。

R5：全native操作とロック解除後の保存パネル・キーボード・VoiceOver・視覚受入。API比較で画面条件を完了扱いにしない。Actions枠ポリシーを維持する。
