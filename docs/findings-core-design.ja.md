# F1 Findings有限契約

モデル・サービスの基盤実装でありLazyweb対象外。固定e75ae371のserver/dto.go、server.go、findings_groups.go、db/findings.go/finding_assets.go、web/src/lib/api.ts/types.tsとFindings一覧/詳細を参照する。

FindingRecordは独立操作ハンドルとノードID、タスク/継承元、任意レポートと証拠バージョン、資産を保持する。重要度/状態/種別など読取値は未知文字列もそのまま保持し、書込は重要度4種・状態9種に制限。IDはDoubleを使わず正のInt64の正規10進文字列。集計タスクIDは整数JSON/10進文字列の両方を正確に読む。タスク内行のノードIDとfinding_idは異なり得る。継承・ハンドルなしの行は変更不可。詳細とグローバル一覧は独立ハンドルの同一性を検証し、context_taskは無関係な由来を受け入れない。

FindingQueryは平坦/グループ/ツリー共通の絞込み。グローバルのタスク絞込みはtask_idであり、別のタスク内配列エンドポイントを選ぶtaskと混同しない。all等は省略し__unassigned__は保持。検索qだけブラウザと同じECMAScript trim。種別/資産名は文字列として維持し、特殊文字/plusは一度だけエンコードする。平坦limit1...200、グループ1...100、正のページと安全なoffset、応答page/page_sizeと重複IDを検査。ツリーはasset_scopeを送らず、右側一覧だけに適用。必須キーの明示的null配列を正規化し、欠落は拒否。ツリー3000ノード上限・UTF8単位の一意キー・親の存在/非循環・非負件数で将来のネイティブ表示を保護する。

FindingServiceは認証済みtransportを注入し、成功200のみ、応答4MiB/書込64KiB上限、await前後のキャンセル、安全な型付きエラー、自動再送なし。詳細はcontext_task任意指定。更新は捕捉FindingRecordと任意name/vulnclass/severity/statusを受け、継承/ハンドルなしを拒否。指定のない項目を省略し、名前/種別の明示的空文字を許す。送信前はブラウザtrim、応答照合はサーバーのGo TrimSpaceも反映しFEFF/NFD/NELを試験。削除はdeleted:trueと正確な数値IDが必要。ソースの複合更新は逐次適用で非原子的なため、サービス失敗は確定した変更結果ではない。後続の状態管理は通信/5xx/壊れた成功を不明として自動再送せず、4xxでも既に前の項目が反映された可能性を考慮する。

F1はCoreのみでfeature-mapはpendingを維持。実行したRED/GREEN、ソースハッシュ付きフィクスチャ、独立ブラウザ絞込み計算、文字列/大ID/null/境界/所有権/継承/未知読取/既知書込/キャンセル/失敗を先行試験。レビュー・全回帰・署名ビルド・同一コミットCIを行う。ホスト実行・VM方針・ブラウザ配備・資格情報・既存状態は変更しない。F2は競合/独立ページ/選択/不明結果、F3はLazywebと固定ブラウザに基づく英日画面、F4は新規VM/独立参照/再起動、F5は出力/通信/レポート/系譜/再検証/深掘りと解除後の実UI/AX/キーボード。最終同等性を狭めない。
