# T8 — ネイティブのタスクテンプレート

固定task-template-controls.tsxは一覧/新規と名前/説明/目標/分類/傍受ルールの5項目を管理します。別名保存は作成中の説明/目標/分類/ルールを引き継ぎ、名前空・未選択で開始、タスクは生成しません。POST201、5項目PATCH200（分類null/ルール空配列も送る）、DELETE200の削除ID一致を要求。作成/更新は選択肢だけ更新し、作成中本文へ自動反映しません。選択中テンプレート削除は選択だけ解除。適用確定時は参照版onApplyと同じく添付件数を0にし、取消では保持。保存済みファイル/下書きUUID/他の作成項目は保持します。

Coreは有限の数値ID、既存の生バイトdecoder、4MiB応答上限、状態/所有ID一致を使用。5項目はブラウザの外側trim、空pattern除去、順序/フラグ/note/原文保持を再現。正の分類、名前120/本文16000のUnicodeスカラーとサーバー空白規則、送信512KiBを確認。NFC/NFD変換や内部BOM除去はせず、一意性はサーバー判断、409は安全な日英案内。不完全/別ID/未確定応答で成功にせず、タスク/エージェント/選択副作用、自動再試行、ホスト実行、ネット/ゲスト変更なし。

window所有モデルに文脈/編集世代/確認IDを保持。項目切替後の遅延入力を拒否し、未保存の切替/新規と削除は対象snapshotで確認。送信ゲートはresetでも完了まで解除せず旧認証結果を破棄。入力/既知4xx拒否は編集を保持、通信/取消/予期しない成功/5xxは結果不明にして再送を禁止し再表示でも保持。明示的なローカル破棄はサーバーへの反映を取り消す操作ではないと説明。確定結果は読込み失敗で消さず一覧/作成選択肢を更新し、無関係な本文を上書きしません。読込みは文脈/チケット照合。通常closeは編集保持、resetはセッション初期化。親離脱で管理文脈/旧読込みを無効化し、送信中ゲートは維持。

本番は保持する作成モデルへサービス注入し、管理/別名保存から子シートを開きます。管理編集中は作成/テンプレート適用や選択/転送と競合させません。明示的な新seedが未保存編集を置換する場合は確認。名前/説明/目標/分類とUUID付きルール行（7種類/両操作）を編集し、既存のルール文言を再利用。言語切替で同一性を変えません。一覧/検索+編集、作成/保存/削除/閉じると確認を参照の階層に合わせ、入力ごとの通信はしません。利用者の中国語/韓国語は原文保持。

LazywebはFrameの保存モーダル(.527892)とCraft削除管理(.52)メタデータで画像未確認、固定ブラウザを比較基準にします。Core契約/境界/Unicode、状態競合/未保存/結果不明/reset、作成側同期/seed/添付件数、画面外の日英UIとカタログをTDDで検証。レビュー/全回帰/署名後に記録し、実操作/キーボード/AX/配置・VM/ブラウザCRUD保存は後続ゲート。タスク/全21機能/実行環境/外部通信/配布は未完了です。
