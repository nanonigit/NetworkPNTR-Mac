# エージェントのプロンプト詳細の検証

サインイン後の一覧からカードを選ぶと、Mac の詳細シートが開きます。プロンプトのタブには変数と現在の本文が表示され、保存済みの各版を展開するとその原文を読めます。終了処理タブには有効なプロンプトと最大ラウンド数を表示します。案件タイムアウト用の指示はゲストが対応する場合のみ表示します。カスタムの終了指示が有効な場合は、組み込みの原文も展開して確認できます。

固定ブラウザ版 `e75ae371ad777ffd1eecdd28d2781a6519b05591` と同じ、認証済みの `GET /api/agents/{key}` を使います。固定版の使い捨て Docker 参照環境で、組み込みの Worker とカスタムの Reporter は認証前に 401、認証後に 200 を返しました。変数はそれぞれ4件と2件、保存済みの版は各1件、通常の既定上限は各10ラウンドで、案件タイムアウト用の指示があるのは Worker のみでした。エージェントは実行していません。

`swift test --filter 'AgentPromptDetailsTests|AgentCatalogTests'` でパス、応答の識別子、原文、既定値、変数ラベルの翻訳、エラー、キャンセルを検証します。画面の項目順は固定ブラウザ版の詳細パネルに合わせ、履歴の概要と本文の分離は Lazyweb の Hygraph と Front の例も参考にしました。

署名済みの Mac 版を新規の隔離 Linux VM に接続して検証しました。日本語で Worker を開くと変数4件、展開できる版1件、案件タイムアウト時の終了処理が表示され、Escape で一覧に戻れました。英語の Reporter では変数2件と版1件が表示され、終了処理の上限は10ラウンドで、案件タイムアウト欄は表示されませんでした。固定版のブラウザ画面はヘルス応答でコミットを確認し、ログイン画面まで到達しました。この新規セッションで利用条件への同意を求められたため、認証後の画面比較は実施していません。使い捨てサービスを停止し、Mac 側の検証用認証情報も削除しました。

Swift 1,060 件が成功し、既存の1件がスキップされました。ゲスト成果物テスト195件、リリースビルド、翻訳生成の整合性、更新したローカルプレビューの署名検証は成功しました。GitHub Actions は利用枠ポリシーに従いスキップしました。

操作ラベルと既知の変数の説明は日英に対応します。保存された本文、版のメモ、変数の例は、初期プロンプトに含まれる中国語や韓国語も含めて原文を表示します。編集、版の差分・復元、モデルと権限の設定、およびブラウザ版との実画面比較の受け入れは今後の段階で扱います。

Mac版の管理ゲストは、既存の `agent_prompts.updated_by` から取得した作成者情報を
履歴APIに追加する。作成者が `system` で、既定値または復元を示す既知の注記と完全に
一致した場合だけ、日英の表示に切り替える。プロンプト本文と元の注記は保持する。
作成者が不明な旧ゲスト、未知のシステム注記、同じ文言をユーザーが入力した場合は
原文表示となる。LazywebのNotion履歴例も参考に、注記は現行版の表示と同じ行に残した。
新しいゲストを組み込んだMac実画面と固定ブラウザ版の再比較は残っている。
