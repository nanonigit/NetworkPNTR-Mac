# T12 メイン一覧の一括操作

固定 e75ae371 はフィルタ/ページをまたぎ選択を保持し、正常取得一覧から消えたIDだけ除く。停止はcreated/queued/running、再開はpausedの選択対象を最大100件。制御後も選択を保持し個別失敗と待機を表示。分類移動は最大100件、解除nullで、1件でも成功なら全選択を解除（管理画面の失敗選択保持とは区別）。削除は専用一括APIがなく固定した5清掃フラグで順次DELETE、進捗・合計・警告を表示し成功IDだけ選択から除く。削除に100件上限を作らない。アーカイブ/復元/ページ分割は後続範囲。

Lazyweb の一括選択/削除確認検索でConfluenceの表と確認 .599384、Floraの確認 .533232 を取得。画像未確認の参考情報に限定し固定ブラウザを基準とする。ネイティブのチェック欄は詳細選択と独立。ヘッダは表示行のみ選び一部選択を表し、非表示の選択も件数表示。操作バーと確認画面に対象ID・移動先・清掃・進捗・個別結果を表示。UIは英日で利用者文字列と状態を保持。実キー/AX/配置比較は解除後。

TaskBulkWorkspace は確認UUID・画面世代・セッション寿命・単一ゲート・workerを保持。同期確保後に処理を起動し、送信前と各応答後に所有権/寿命/キャンセルを検査。リセットで状態を消しても処理終了まで共通ゲートを保持。画面終了は残りを中止し同一セッションの確定/不明結果を残す。選択は正常取得IDと親画面の競合を検査し、エラー時には削らない。古い入力やフィルタで固定対象を変更しない。自動再送なし。

TaskStoreは分類・通常操作と排他し、開始/終了で古い取得を無効化。成功した分類/制御/削除だけを反映し、他情報と選択/実行IDを保持（削除確定IDは除く）。削除の非負Int64件数はDecimalで集計し桁あふれを防ぐ。警告は有無だけ保持し本文を表示しない。既知拒否は他IDを継続可、通信/5xx/不正応答はID単位で不明として重複再送しない。キャンセルは未開始分を止め、処理中は不明、残りは未開始。401/403は残り停止。旧セッション結果を破棄し、再取得失敗で成功を消さない。不明ブロックの解除は固定IDへの明示確認で、サーバー変更の取消を主張しない。

TDDで共通ゲート/古い応答/投影、順次性・進捗・フラグ・合計、状態選別と部分成功、選択方針、不明/拒否/キャンセル、送信前後リセット、非表示選択と古いBinding、英日画面外構築を検証。レビュー・全体回帰・署名・翻訳とCIを確認。今回実タスクへの停止/再開/削除は行わない。実VM操作・全21機能/ブラウザ画面・クラウド・カーネル・配布は未完了。
