The complete standalone Traffic/21-workflow/VM/browser/provider/harness/release target remains unchanged. Blob-original saving is an added extension, absent from the frozen Traffic page. Do not interpret rendered `@blob` text as an authoritative export manifest: an inline response may contain an identical literal. Keep raw traffic text untouched. This backend/CLI phase is outside Lazyweb's UI boundary; use Lazyweb before adding save controls.

Add a separately versioned managed backend extension over exact source e75ae371; preserve the clean browser checkout. A new authenticated GET /api/traffic/blob-metadata?id=OPAQUE&side=request|response returns id, side, lowercase64hex hash and Int64 size only for a stored oversized blob associated with that exact SQLite exchange side. Read structured exchange_bodies plus exchanges metadata, validate side/hash/nonnegative length and existing blob file size. Inline/legacy records without structured blob metadata, absent rows/files and mismatched lengths are unavailable; never infer metadata from HTTP headers, marker strings, guest filenames or arbitrary URLs. Existing hash GET /api/traffic/blob remains the fixed streaming data route; host staging must verify exact length/SHA256 and current auth/VM/UI ownership before atomic publication.

Source traffic deletion may make unbound source blobs unavailable; already-bound snapshot export remains independent and unchanged.
