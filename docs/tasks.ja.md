### P4 エージェントごとの Web 検索と対話型シェル

固定ブラウザ版に合わせ、対応エージェントの設定を表示する。ゲスト全体の Web 検索が有効と確認できるまで、個別の検索スイッチは操作できない。変更した Web 検索を保存する直前にも全体設定を確認する。対話型シェルとほかの設定は個別に編集できる。

既存の変更項目だけを送る仕組みと認証済みの読み直しを使う。非表示、操作不可、未編集の値は保持する。理由はスイッチの近くに表示し、Lazyweb の Square と Workflowy の設定画面も参考にする。全体設定、リクエスト、編集中の設定変更を試験し、ツールとエージェントを実行せず固定版と照合する。

### P4 エージェントの MCP とスキルの表示設定

ゲストに登録された MCP サーバーとスキルをエージェント編集画面に表示し、現在の紐付けを読み込む。各チェック欄は固定版ゲストの項目別 API で保存する。保存後に紐付けを読み直し、一覧カードの件数を更新する。

現在の詳細のエージェント ID とカタログのリソース ID を使う。空の一覧と取得失敗を区別し、保存結果を確認できない場合は再試行前に読み直す。固定版と Lazyweb の権限一覧を参考にチェック欄を配置する。送信内容、反映確認、失敗時を試験し、使い捨ての Mac 版と固定ブラウザ版で照合する。
