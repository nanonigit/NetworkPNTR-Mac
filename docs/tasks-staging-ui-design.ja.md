# T6 — タスク作成の添付

固定tasks/page.tsxは下書きUUIDでアップロードし、absパスを日英の見出し/説明と箇条書きで本文へ追記します。サイズはMB/KB小数1桁または整数B、末尾空白はJS規則、通常の閉じるで保持/作成成功でUUID更新、転送中は作成不可。Lazywebのfile attachment upload form検索はany.doデスクトップ問い合わせフォーム(.452713、https://www.any.do/contact_form)と隣接DoorDashモバイル報告(.9)のメタデータを返しました。画像は未確認なので実画面の合格証拠にせず、固定ブラウザを基準にします。

一覧生成は日英/追加/言語切替の見出し判定/空白/原文バイトを参照版と一致させます。JS toFixed(1)に合う整数丸め（1280B→1.3KB等）を使用し、ファイル名を翻訳テンプレートへ再解釈させません。言語変更だけでは既存本文を変更せず、カタログは英日のみ、ファイル/ゲスト/利用者内容は原文です。

作成モデルが保持する下書きUUID・確定件数・転送ID/進捗/失敗・選択状態・取消可能worker/pumpを追加。従来試験はoptionalなtyped uploader注入を維持し、本番はRoot→TaskScreenModel→creationへ認証クライアントを明示注入します。文脈ID/不確実な作成/テンプレート確認/転送/選択/事前取消を確認。成功時だけ最新本文へ操作開始時の言語で追記し、タスクを暗黙作成しません。転送中の通常入力は許可、テンプレート上書きは競合防止で禁止。選択/転送中は作成を禁止し、進捗は送信済バイトで保存済証明にしません。部分失敗/取消で件数を増やさず自動再試行/削除も行いません。

通常の閉じるは転送を取り消しIDを無効化、確定本文/件数/下書きIDを保持。再表示時は安全な中断案内。破棄/リセット/作成確定はUUID更新と添付状態初期化、ログアウト後や旧転送の遅延処理は新操作へ影響させません。既存のwindow所有ChatAttachmentPickerButtonを再利用し、選択/表示/失敗コールバックも文脈IDで守ります。選択中は閉じる/破棄不可、転送中は明示的に閉じて取消可能、busy時の暗黙シート閉じは禁止。言語変更で同一性を変えません。

TDDはCore一覧/丸め/翻訳、状態の成功/失敗/閉じる/再表示/リセット/競合/作成・選択ガード、UI接続/画面外の日英試験の順。参照ソースのoracle、全体回帰、レビュー、署名リソースとビルドを確認します。実クリック/進捗/取消/キーボード/言語/配置/AX、同一ファイルのVM/ブラウザ比較は実機・ロック解除後のゲート。カーネル安定性や全21機能の合格とはしません。固定比較版/通常ゲストは保持します。

ライフサイクル追加：選択コールバックはTaskCreationUploadSelection経由で、既存ChatFileAccessを転送/取消の後片付けまで保持します。取得前/取得後に文脈を確認し、取得済み権限だけ解放。画面離脱時のTaskScreenModel.stopでも選択状態を解除し、確定下書きを保ったまま作成文脈を閉じて無効化。作成送信中は従来ガードを維持し、移動/再表示後の旧コールバックを拒否します。
