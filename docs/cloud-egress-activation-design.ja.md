# クラウド中継プレビューの有効化

通常の Mac アプリは、診断モード外で `--cloud-egress` を明示した場合に
プレビューを有効にする。専用の状態ディレクトリと Keychain アカウントを使う。
標準起動では従来の状態を使い、中継を閉じたまま起動する。この段階は起動経路の変更。

VM の生成前に、同梱マニフェストが署名済み実機試験の候補と完全に一致することを
確認し、そのマニフェストでカーネル・initramfs・ディスクを検証する。
DesktopRuntime はゲストが準備完了した後、認証を公開する前に本番中継を開く。
起動時に指定しない場合は本番中継を開けない。停止と失敗時は中継を閉じる。

マニフェストの受け入れと拒否を試験した後、通常の DesktopRuntime で中継あり・なし
の起動を行い、準備完了、認証、停止後の中継解除を確認する。新規ディスクを使い、
プロバイダーのキー入力や要求送信なしで検証する。
