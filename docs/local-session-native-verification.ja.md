# 自動ローカルセッション：署名済みアプリのサービス検証

[English](local-session-native-verification.md) | [日本語](local-session-native-verification.ja.md)

初回の記録は通常版とCloud Previewへの適用前に、別に署名した使い捨てアプリで行ったサービス試験です。適用後の状況は末尾の11月19日の記録を参照してください。

通常版の新規起動・再起動、通常版の従来パスワード環境からの移行・再起動、クラウド版の新規起動・再起動、クラウド版の従来環境からの移行・再起動の4ケースが、それぞれ最初の記録された試行で通りました。合計8回の起動です。各版のカーネル、CPU、2 GiBメモリ設定を維持しました。通常版は2 CPU、クラウド版は1 CPUです。成功するまでの反復や、別カーネルへの切り替えは行っていません。

固定ソースと成果物、JWTなしAPIの401拒否、自動認証と再起動、既存bcryptハッシュ、ダミーのプロバイダーキーと設定、投入済みの終了タスク・履歴の全行、実APIのInt64集計を確認しました。新規自動接続ケースでは前回起動の接続用トークンも403で拒否しました。ツールの子プロセスには接続用トークンが継承されないことを確認しています。正常停止後、各ケースの全ゲストログ2件について、隔離の記録、両起動の内部認証情報とダミー情報の非出力、障害分類ゼロを確認しました。生の認証情報、利用者データ、VMディスクは公開用記録に含めません。

診断処理は、開始条件、処理、レポート保存に失敗すると非ゼロで終了します。保存失敗の伝播も回帰試験に含めました。制御APIと実際のローカルIPCクライアントを使うMCP試験では、401の直後に権限が失効し、次のバックエンド要求が出ないこと、再接続で権限が復活せず操作も再送されないことを確認しています。

[検証記録](../evidence/local-session/native-service-verification.json)。この8回だけで、既知の間欠的な起動障害の受け入れ条件を閉じません。Macがロックされているため、実画面での直接利用、日英表示、ブラウザ版との機能比較は未完了です。

クラウド候補の最初のマニフェストに、親版の古い `managedBackend` 情報が残っていました。修正版は親情報を別に保存し、新しいバイナリと実際の `dev` ビルドバージョンを示します。カーネル、初期RAMディスク、システムディスク、バックエンド自体は同一です。[修正済みマニフェスト](../evidence/local-session/cloud-composite-manifest.json)。Core側の許可ハッシュとの一致と、親・新バイナリの区別を回帰試験で確認します。

クラウドへの実通信の回帰試験は不合格です。無効なテスト値による4社のモデル一覧要求で、上流のHTTP状態を確認できませんでした。変更前のバックエンドを対照にしても、観測情報を追加した自動接続版でも、全社が `unexpected-eof` になりました。システムのcurlでは同じOpenAIホストから401が返り、TLS1.2でも接続しました。一方、本番C通信処理を使う診断はTLSより前のTCP接続待ちで期限切れになりました。原因は未確定です。失敗を残し、接続先・証明書の検証を緩めたり、通信試験を合格にしたりしません。[調査](bugs/local-session-cloud-egress.ja.md)と[記録](../evidence/local-session/cloud-egress-regression.json)を参照してください。

一時タグの修正後の後処理は、両候補イメージを使う実Docker試験にも通りました。親の自動削除を無効にし、入力の永続参照を保持したまま所有タグだけを削除しています。更新前のアプリ内ゲストファイルも保持しています。初回のキャッシュ参照2件の消失は以前の記録に残し、その元イメージIDまで復元したとは扱いません。

## 2026年11月19日の適用結果

ローカル署名済みのビルド3は、通常版・Cloud Previewとも直接起動と通常終了後の再起動でダッシュボードを表示しました。通常版は既存の専用ディスクを再利用しました。Cloud Previewは起動引数なしで、バンドルの設定に基づいて専用ディスクと許可済みプロバイダーへの経路を選びました。アカウント項目とパスワード画面は表示されませんでした。使い捨ての検証アプリでは実際の言語メニューで日本語 → 英語 → 日本語に切り替えました。検証したウィンドウ幅では、英語ダッシュボードの「Source」に途中改行が残っています。

ユーザーがLittle SnitchをAllowに変更した後、署名済みのVM診断でOpenAI・Anthropic・GroqはHTTP 401、Geminiはキー無効を示すHTTP 400を返しました。実キーでのモデル一覧取得・推論と通信の反復安定性は未確認です。

Swift 1,227件（スキップ1件）とPython 222件に失敗はありませんでした。固定ブラウザ版との一覧比較は主要21機能・27画面・243ハンドラーで一致しました。全機能の操作と画面の同等性は引き続き検証対象です。[検証データ](../evidence/local-session/deployment-verification.json)
