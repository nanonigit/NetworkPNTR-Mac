## 実装・証拠

TrafficBlobDownloadはIDの生バイト、厳密なside、非負Int64長、正規SHA256を検査し、認証付き固定メタデータ／ハッシュ経路だけを使用する。既存の有限バッファ転送・非公開ステージング・上書きしない公開・整合性レシートを共有し、Finding保存の公開契約を維持した。追加9件はBOM/NFD等のID、大きい長さ、型付き認証転送、実ファイルの整合性、ログアウト、遅延応答、VM所有権、キャンセル、401を検査する。BOMを失うテスト側URLデコードは独立したpercent-byte検査に修正し、NSObject.hashとの名前衝突は有効なRED前に修正した。ゲストのファイル名、本文中のマーカー、記録URLから保存先を決めない。

CPU1／arm64／NIC0／共有0の使い捨て候補に、固定Go環境でローカルビルドしたバックエンド0cbb7cb32f05843de7b733fb76ed4e22b9b2acd386878d4ce34b89d819a3750aを搭載した。候補のカーネル・initramfs・systemと、ソース／レシピ／バイナリの来歴は検証記録に含めた。誤ったチェックサムはコンテナ内のファイルシステム生成前に拒否された。これは入力の負試験であり、業務ロジックのTDD REDではない。固定ブラウザと通常プロファイルを維持し、Dockerはビルド・試験のために使用した。

検証ソースはa42c40ad9508f7e28fdc3d96c730406084225af7、署名済み診断バイナリSHA256は372c428d2c461d41e9caa0c458b77034e11bd640b68d9fe445338b3005f704e6。実行exit0、2回起動・2回協調停止・2回監査を通過し、永続化と固定ブラウザ参照結果が一致した。参照SHA256はc4601040b7a0abba258a81f65183ef81bb6116d7bf5f47c743ffe1ebcac6b8e6、実行レポートSHA256は02bea2d5a5589274fc3388e6a8e77a732df3252208cab1f0b512035d37e622b3。保存・再起動後の両ファイルは262401バイト、SHA256 5549252a7f275dd6b221f062c298ac588a2dea19e5145b6ca06308cc8c9dd43eで、独立した全バイト再読込も一致。インライン／blobなしと不正長では公開を拒否した。実VMの停止・マシン解放後、元の認証リビジョンが有効でタスクがキャンセルされていないことを確認して、保留中の公開拒否を検査した。再起動では再投入せずメタデータと元ファイルを再照合した。因果関係の回帰とレビューは[RCA](bugs/traffic-blob-proof.ja.md)に記録。

## 残る受け入れ

転送途中の中断は専用の証人で別に検証する。本文UI、root／ウィンドウ／保存パネル所有権、複数ウィンドウ、キーボード、VoiceOver、全21機能の比較は未完。Macのロック解除はユーザーが後回しにしており、画面外の試験をUI受け入れとしない。通常カーネルの安定性／昇格、Gemini・Groqを含む4社CP1–CP4、調査ハーネスH0–H5、リリース条件も継続する。今回は内部処理・CLIであり、保存UIの設計前にはLazywebを使用する。

Release VMProbeのビルド成功。--captured-blobに3つの位置引数を渡してもDEBUG専用の使用法を表示しexit2になる。全シンボルのdemangle結果にSourceBlobProbe、CapturedProbeContract、WithheldResponse、exportOwnershipWitnessはなく、元データ検証専用の文字列も含まれない。これは診断機能の除外検査であり、製品リリース受け入れではない。
