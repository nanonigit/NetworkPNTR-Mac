# クラウド中継プレビューの起動検証

署名済み VMProbe で、Mac アプリと共通の DesktopRuntime の起動・停止処理を使った。
改変したマニフェストを VM 生成前に拒否し、検証済み候補では有効・無効の両方を起動した。
どちらも初回認証の準備が完了し、明示的に有効にした起動だけで本番中継が開いた。
無効時に直接中継を開こうとする操作も拒否した。停止後は VM と中継の解除、
ネットワーク機器なし・共有マウントなしを確認した。その後、別ディスクで
4社の模擬通信の回帰試験を行った。

固定したゲストを同梱した ARM64 Release のプレビューはアドホック署名済み。
`open -n "/path/to/ARTEX Mac Cloud Preview.app" --args --cloud-egress` で起動する。
プレビュー専用の状態と Keychain アカウントを使う。引数を省いた場合は通常の起動方針が
適用される。起動検証ではプロバイダーに要求を送っていない。GUI の実起動、実 API、
プロバイダー選択画面、固定ブラウザ版との比較は今後の検証項目。
