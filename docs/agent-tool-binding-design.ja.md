# エージェントへのツール割り当て

## 要件

固定ブラウザ版と同じ割り当て操作を提供する。`traffic_search` と
`traffic_get` はトラフィック記録が有効なときに変更できる。
変更対象は1人のエージェントの割り当てだけとし、ツールの説明、スキーマ、
実行定義、有効状態、他のエージェントの割り当てを保護する。

## 設計

管理ゲストに認証付きPUT `/api/agents/{key}/tool-bindings/{tool}` を追加する。
本文はサイズ制限付きのJSON真偽値。保存後は両方のキーと割り当て状態を返し、
読み直しには既存のツール一覧を使う。トランザクションでエージェントの削除を
防ぎ、必要な場合は保存済みのトラフィック記録設定をロックして確認したうえで、
ツール行をロックする。希望の状態と一致していれば書き込まない。
旧データのJSON nullは空の割り当てとして扱う。不明なキーや壊れた形式は拒否する。
固定ブラウザ版が使うツール設定全体のPUTは従来の契約を維持する。

## 試験と統合

不正入力がデータベースに届かないことを確認する。使い捨てのPostgreSQLで、別々の
エージェントへの同時変更、繰り返し、異常データ、トラフィック記録条件を検証する。
次段階でゲストイメージの採用とSwiftUIの操作をつなぎ、固定ブラウザ版と比較する。

固定ソースへのパッチ適用とLinux arm64ビルドを確認し、ネットワークを遮断したビルド内で
trafficとserverのテストが通った。専用のPostgreSQL 16では入力境界とトランザクションの
試験が通った。同時追加、追加・解除の繰り返し、存在しない行、旧形式のnull、不正な配列要素、
他のフィールドの保護、割り当ての前後で記録が無効な場合を確認した。
検証用データベースはポートを公開せず、試験後にコンテナを停止した。
導入済みプレビューの同梱ゲストは現行版を使用している。
