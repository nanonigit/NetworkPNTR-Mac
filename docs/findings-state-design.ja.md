# F2 Findings状態の所有権

状態基盤のみでLazyweb対象外。固定ブラウザpage.tsxの設定/条件変更、平坦/グループ独立ページ、クエリ識別子、5秒更新、ツリーのスナップショット、ページを跨ぐselectedIdsを維持する。通信契約はF1。画面/機能受入、ブラウザ/VM変更は含まない。

観測可能なFindingReadState<Value>は最終成功値/取得中/古さ/安全なエラーと非公開の要求世代を保持し、FindingPageState<Value>はページ/件数/1回補正を担当。FindingStoreは平坦・グループ見出し・ツリー・統計・詳細・展開グループの個別状態を持つ。await前にクエリを捕捉し、条件/停止/リセットで読取世代を無効化して古い応答や後始末が新しい取得を消さない。同じ条件の非表示キャッシュは古い値として保持し、条件/資産範囲が変わる集合は破棄。条件変更で全ページ/展開/ツリー/詳細をリセットし、独立統計とページを跨ぐ出力選択は保持。選択IDは独立レコードの正規ASCII ID。資産キーと検索指紋はUTF8 Dataで比較し、正規等価な別スコープを混同しない。グループ操作は現ページ見出しの所有権が必要。資産範囲変更で平坦を1ページ目へ戻し、ツリー取得には範囲を渡さない。

現在の表示の更新は捕捉したサイクルで順次取得し、所有権が変われば次の要求を開始しない。各読取は重複を抑制し、取得済み/展開中/現見出し内グループだけ独立ページを更新。表示と統計は独立した5秒ループで単一起動/停止を管理。資産表示のツリーは最初の一度で定期再取得せず、統計は継続。明示更新ではツリー/一覧を更新可能。待機中の表示変更も古いループを再開せず判断する。ページ補正は(total-1)/size+1で桁溢れを避け、同じ所有権の成功読取後に1回だけ追加取得する。

変更は捕捉した所有権/表示または詳細ハンドル/変更可能な由来/項目と本文/事前キャンセルを確認後にサービスへ渡す。停止/リセットでも同じ呼出しの終端まで単一ゲートを保持。サービス引渡し後の全失敗はHTTP4xxも不明扱いとし、逐次PATCHのロールバックを主張せず自動再送しない。確定した既知キャッシュだけ更新/削除し、削除時はその選択/詳細を解除。取得失敗でlastConfirmationを消さない。不明IDは捕捉セッションの明示確認まで次の変更を止める。停止は活動世代を無効にし、同一セッションの遅延完了は表示を破棄して不明IDを保持。リセットはセッションと表示/選択/不明を切り替えるが旧呼出しのゲートは終端まで保持。古い完了で新しいゲートやデータを変更しない。

制御した停止点での逆順応答、条件/表示/UTF8、ページ独立と補正、ページ間選択、ツリースナップショット、古い値/エラー、詳細文脈競合、停止/リセット/キャンセル、旧新ループ、変更確定後の取得失敗、壊れた/4xx/5xx/通信失敗、不明と明示確認、読取専用/捕捉対象、リセットを跨ぐ保留変更をRED/GREENで試験。レビュー/全回帰/カバレッジ/署名/同一コミットCIの後にF3英日画面とF4実ゲスト比較へ進む。高度な出力/通信/レポート/系譜/再検証/深掘りと実画面/AX/キーボードは後続必須。
