# プロバイダーメニューの検証

固定ブラウザ版 `e75ae371ad777ffd1eecdd28d2781a6519b05591` のソース、
以前に採取した操作項目と画面画像を確認した。ブラウザ版の「新規」はプロファイル
一覧の上でローテーション設定と並ぶ。Mac でもその位置にプロバイダーの選択肢を置いた。

| 操作 | 固定ブラウザ版 | Mac |
| --- | --- | --- |
| 手動で新規設定 | 「新規」で空のフォームを開く | 「新規」→「カスタム設定」で空のフォームを開く |
| プロバイダーの選択 | フォームで通信形式と接続先を指定 | Mac の追加機能として「新規」から4社の初期値を選べる |
| キー入力・モデル取得・接続テスト・保存 | フォーム内で明示的に操作 | 従来のフォーム内で明示的に操作 |
| 保存済み設定の編集 | 既存プロファイルを開く | 従来の編集操作とキーのヒントを使う |

5種類のフォームを日英でオフスクリーン構築し、毎回新しい識別子でキー欄が空になり、
構築だけでは通信が発生しないことを確認した。モデル取得と保存は制御された通信先への
契約試験を実施した。「カスタム設定」は日英カタログの試験に含めた。同じゲストを同梱した
ARM64 プレビューを再ビルドし、厳格モードで署名を検証した。

実画面での選択、キーボード操作、VoiceOver、実 API、今回のネイティブ画面と
ブラウザ画面の比較は今後の検証項目。
