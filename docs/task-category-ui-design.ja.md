# T10 カテゴリ画面設計

固定ブラウザ版 e75ae371 の管理は左に新規・カテゴリ・未分類と件数、右に名称編集と所属タスク。削除は名前と件数を確認しタスクを未分類に戻す。カテゴリ間のドラッグ移動、複数移動の対象確認、作成フォームの即時作成/選択、全件/未分類/ID フィルタに対応。削除済みドラフト ID は選択肢上で不明として保持し、利用者が変更するまで本文や選択を勝手に上書きしない。

Lazyweb の検索で Todoist のラベル一覧メタデータ .568245、done のカテゴリサイドバー .532112 を取得。画像は未確認で参考情報に限り、画面一致の証明としない。固定ブラウザを基準にネイティブの一覧・編集・所属タスクを実装。移動メニューと管理内の複数選択/確認、ローカルのタスク ID のドラッグに対応し外部ファイルやURLを扱わない。メイン一覧の一括操作全体は後続。UI は英日、利用者文字列は原文のまま。言語変更で状態を再生成しない。

ウィンドウ単位の TaskCategoryWorkspace が一覧、タスク、読み取りエラー、画面/編集 UUID、分類選択、固定した確認内容、選択タスク、変更ゲート、結果不明状態と型付き結果を保持。管理と即時作成は同じゲートを使用。即時作成は親作成画面 UUID を固定。編集を破棄して切り替える場合は確認し、通常の終了は入力保持。削除・移動の対象は確認時に固定。UI 確定時に同期的にゲートを取得し、処理開始前と応答後にセッション寿命を確認。リセットでも実行中ゲートを早期解放しない。既知の入力/4xx拒否は修正可、通信・5xx・予想外応答は結果不明として自動再送せず入力を保持。明示的なローカル破棄のみで解除する。

変更の開始/終了時にカテゴリ・タスク・TaskStore の読み取りを無効化し古い応答による復活を防ぐ。確定結果だけでローカル一覧を更新し再読込失敗と区別。選択中/実行中 ID、本文、状態、モデル、件数を保つ。部分成功は成功 ID のみ移動し失敗を残す。移動後の件数は再取得または古い表示と明示。作成フォームは同一親 UUID の確定作成だけ選択し、本文や添付を保持。子画面中は親終了・破棄・作成・アップロード・テンプレート管理を保護。画面停止/セッション終了で古いコールバックを拒否。

TDD は結果反映/フィルタ/Unicode、編集中切替、削除/移動対象の固定、部分成功、遅延応答、送信前後リセット、結果不明保持と明示破棄、競合拒否、再読込失敗、即時作成と親入力保持、古い Binding、英日画面外構築を検証。全体回帰・レビュー・カバレッジ・署名と翻訳同梱を確認。実ブラウザ/VMの CRUD・移動・即時選択・ドラッグ・キーボード・AX・配置・言語切替・永続化は後日の解除後に確認する。全21機能、クラウド、カーネル安定性、配布は未完了。
