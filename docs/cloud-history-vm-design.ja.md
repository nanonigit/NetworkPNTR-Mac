# VM再起動をまたぐ署名付き履歴の再送

管理対象cloud2をCPU1、NICとホスト共有が0の使い捨てLinux VMで使う。読み取り専用のシステムディスクに候補専用のループバック模擬サービスを組み込む。固定モデル・パス・合成Bearerを要求し、初回だけゲスト内の揮発ファイルをReadする。模擬サービスが署名付き呼び出しと実結果を照合し、結果のダイジェストを専用状態ディスクに保存する。再起動後は同じ署名と結果を要求し、過去と新規のターンを検証して完了マーカーを返す。揮発ファイルは初回起動にだけ置く。

署名済みDEBUG VMProbeは本番の認証、LLMService、ChatServiceを使う。通常APIで設定と会話を作り、初回完了を待って正常停止し、同じ状態ディスクを再起動する。元の設定・会話・活動IDを確認して次の発言を送り、完了応答と元のRead／結果1組を照合する。停止後のシリアルログで模擬サービス、資格情報、隔離を監査する。組み立て済みmanifestのハッシュで両起動を固定する。壊れた履歴、誤署名、順序違い、結果の改変を試験する。実クラウドとブラウザ比較は別の条件とする。VM／CLI作業のためLazywebは対象外。
