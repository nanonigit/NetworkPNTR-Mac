# T10 ネイティブのカテゴリ画面チェックポイント

Tasks からカテゴリ管理を開き、カテゴリ/未分類と件数、新規・名前変更・削除、所属タスク、単独移動メニュー、複数選択と移動先確認、ローカルタスク ID のドラッグ先を実装。一覧にカテゴリ列とフィルタを追加。作成画面の子画面で新規/既存カテゴリを選択し、本文とドラフト UUID を保持。UI は追加26項目の英日カタログと、言語に依存しない所有権を使用。中国語・韓国語を含む利用者の名前は保持し、小文字化後の UTF8 照合で NFC 同一視を避ける。
