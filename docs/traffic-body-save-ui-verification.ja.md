## 動作

アプリ所有TrafficBodyExportRetirementを詳細・ウィンドウ・認証画面置換より長く保持する。回収を重複させずポーリングなしで終了を観測し、処理中のmodelを保持、清掃失敗を安全な日英通知に縮約してmodelを解放する。通知を閉じてもファイルは消さず、重複回収で通知を復活させない。throwされた清掃失敗と、保存成功でもステージング清掃が不完全な場合の両方を保持し、その所有者で再試行させない。ディレクトリ同期警告と清掃失敗を区別する。

RootViewにTrafficServiceのメタデータとAuthenticationSessionの型付き転送を注入し、ArtexMacAppの共通回収器を使う。稼働VMと認証セッションの世代を固定し、停止・再起動・ログアウト・再ログインで旧所有者を失効させる。TrafficRawPreviewは提示lease・store所有者・詳細revision・ID生バイトとゲスト対応が一致するときだけ保存操作を出す。既存のウィンドウ付きEvidenceSavePanelPresenterで保存先を選ぶ。転送中はsideを変更せず、取消・進捗・保存後のSHA256／長さ・安全なエラーには既存日英表示を使う。消失時は取消、親終了時は回収を待つ。表示本文の@blob、ゲストファイル名、記録URLから情報や保存先を決めず、生パケットの表示・コピー・折返しは維持する。

固定ブラウザe75ae371の独立画面は生データviewer、Finding側は本文ダウンロードの参照であり、独立画面への元データ保存は拡張として区別する。Lazywebの参照と限界は設計記録にある。ソースや画面外試験から新たな画像・実操作の受け入れを推定しない。通常ゲストには管理版blob能力がなく保存操作を隠したまま、実験用ゲストへ昇格しない。
