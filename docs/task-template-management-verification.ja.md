# T8 テンプレート管理の検証

一覧・検索・新規・作成・編集・削除、カテゴリ、7種類の通信ルール、タスク作成からのテンプレート保存を実装。確定した保存・削除は選択肢に反映し、作成中の本文を上書きしない。UI は英語・日本語のカタログを使い、利用者の本文・名前・ルール・注記は元のバイト列を保持する。設計と比較元は task-template-management-design.ja.md を参照。

RED 記録: ca3f5c3 API 未実装、c335184 管理モデル未実装、bfbff72 UI 連携未実装。39db058 の実行でテンプレート適用後の添付件数が 1 のまま残る差と、削除前に開始した GET による再表示を再現。33ff113 ではリセット直後に古い削除が送信される競合を再現した。適用確定時だけ表示件数・古いエラーを消し、ドラフト UUID と保存済み添付を維持する。キャンセル時は件数を保持。変更開始時に古い読み取りを無効化し、画面・編集・確認・セッションの所有権を照合する。結果不明の操作は入力を保持し、自動再送を禁止。

管理モデルの集中試験、Swift 全体カバレッジ試験、Python 回帰、翻訳書き出し確認、固定ブラウザ版の構成照合、署名付きアプリのビルドを検証する。最終件数と署名結果は tasks.ja.md に記録。今回の検証では実ウィンドウを開かず、VM を起動せず、比較元データを変更しない。英日 NSHostingView の画面外構築は構造確認に限る。キー操作・確認ダイアログ・VoiceOver・配置・実際の言語切り替え・保存永続化の比較は、利用者による後日の Mac ロック解除後に実施する。Tasks は部分実装で、全21機能・クラウド通信・ゲスト安定性・配布の受入条件は未完了。
