# ゲストの出力言語

Macで選んだ英語または日本語を、認証済みの専用ゲストの出力言語にも適用する。
ログイン時と再起動時も同期する。固定ブラウザ版と保存済みのプロンプト本文は保持する。

固定版の設定APIから現在値を読み、異なる場合だけ出力言語を送信し、応答を照合する。
保留中の選択を最新値にまとめて直列に処理し、書き込み前に認証の世代を確認する。
結果が不明な要求は自動再送せず、次の言語変更や認証時に同期できるようにする。
失敗時のログに応答本文や認証情報を含めない。

日英の値、旧設定の値、既に一致する場合、通信中の切り替え、ログアウト、
不正応答を試験する。固定ブラウザ版の契約と比較し、専用VMで永続化を確認する。

固定ブラウザ版の使い捨てAPIで `ko`、`en`、`ja` を順に保存し、
トラフィック記録、LLM記録、Web検索の設定を保持した。署名済みの実機検証では、
Mac版の同期処理を現行ゲストにつなぎ、旧値の `ko` から `en`、`ja` に変更した。
両方とも再起動後に読み戻せた。3回の起動で仮想NICとホスト共有は0で、VMは正常停止した。
言語メニューの実画面操作と実際のモデル生成は未確認。
[検証記録](../evidence/llm/guest-output-language.json)

プロバイダーへの送信境界では、同じ会話の次のリクエストで出力指示が英語から日本語に
切り替わることを検証する。模擬OpenAIはシステムメッセージ内の既知の指示を調べ、
言語コードだけを記録する。4社のストリーミングと通信中の停止も引き続き検証する。
実モデルが指示に従うかは別の確認項目とする。

署名済みのVM試験で、模擬OpenAIの同じ会話の2ターンが完了し、システム指示が
`en` から `ja` に切り替わった。4社のモデル一覧、4社にわたる計5回の
ストリーミング完了、停止時の通信キャンセル1件も確認した。
検証記録には言語コードと経路名だけを残した。
[プロバイダー境界の検証記録](../evidence/llm/guest-output-language-provider-boundary.json)

固定ブラウザ版の5種類のエージェントを対象とする既存のGoテストも、対象の
ソースファイルを照合し、ネットワークを遮断したビルダーで実行して通過した。
