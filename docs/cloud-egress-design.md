# Cloud API egress for the dedicated VM

Keep the Linux VM without a NIC, host share or generic host RPC. The app owns one guest-to-host virtio socket service for provider API exchanges. The guest selects a provider and operation, supplies its own credential and JSON bytes, and receives a bounded response. The host constructs the request to a fixed authority on HTTPS port 443. It terminates TLS so it can enforce both the HTTP authority and TLS identity even when providers share an IP. The broker handles request credentials in memory for that exchange. Persistence remains in the guest.

Allow model discovery and Chat Completions for OpenAI, Gemini and Groq. Also allow OpenAI Responses and Anthropic models and Messages. Use fixed method/path pairs, a generated Host, a bounded key and body, provider-specific authentication and response framing. The guest cannot supply URL, Host, proxy, arbitrary headers or HTTP framing. Do not follow redirects. Each request resolves a fixed absolute DNS name. Reject the complete answer set if it contains a scoped or special-purpose address, then dial a vetted numeric result with the fixed hostname for TLS identity. Bound resolution, connect, admission, response and cancellation before enabling the listener. A socket operation belongs to the boot that accepted it, and VM stop closes its listener and exchanges.

The four-provider broker covers cloud APIs. General web access, custom endpoints and investigation tools need their own policies and acceptance tests. No guest socket is opened in the default runtime until the lifecycle and isolation tests pass.

Sequence: A implements request and DNS admission, numeric endpoint and TLS identity checks, and offline negative vectors. B implements the direct transport, framed vsock protocol and streaming response exchange, with cancellation, resource caps and VM lifecycle. C proves a signed VM cannot dial independently, denied input produces no upstream traffic, fixed requests stream across vsock, and shutdown cancels in-flight exchanges. D tests the four real APIs with keys entered in the app. Compare shared workflows with the frozen browser and keep English/Japanese UI acceptance separate from the backend checks.

Direct transport must bypass proxy selection and verify the connected socket's numeric peer and port before sending request bytes. Network.framework's proxy preference can fall back to a configured proxy. The initial system libcurl diagnostic proved direct TLS feasibility. The [current transport design](cloud-egress-transport-design.md) uses a caller-owned TCP socket and explicit offline certificate evaluation. [Apple Technical Support](https://developer.apple.com/forums/thread/828775)

Address policy uses the IANA [IPv4](https://www.iana.org/assignments/iana-ipv4-special-registry/) and [IPv6](https://www.iana.org/assignments/iana-ipv6-special-registry/) registries. The policy is conservative and excludes special-purpose ranges even when the registry lists a globally reachable exception.
