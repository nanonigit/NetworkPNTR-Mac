# T11 カテゴリ・テンプレートの実環境比較

T9/T10 のソフトウェア試験と署名ビルドだけでは DB 変更を証明できない。B1/T7 の独立したソースカーネル候補を使い標準を置換せず、新規の私有2GiB状態ディスクで1回だけ起動する。認証は生成したセットアップ/パスワード/セッションをメモリに保持し、Keychain/APIキー不使用。NIC・共有・一般ホストRPCなし、設定前401と初期化前状態を確認。停止後の完全ログで隔離・異常・初期化・資格情報不在を監査。操作成功後の終了失敗も完了扱いにしない。失敗状態とログは私有領域に保存し、同条件の成功待ち再試行をしない。

本番クライアントで初期タスク/カテゴリ/テンプレートが空と確認。カテゴリ作成（空白正規化と件数0）、同名409、改名。カテゴリとルール付きテンプレート作成、NFD・内部FEFF・日中韓の固定データ保持。カテゴリnull/ルール空配列の更新と再取得、関連再設定、カテゴリ削除でテンプレートのカテゴリがFKによりnullになることを再取得。不存在タスクの単独移動404、2件の複数移動は順序付き全失敗/null。テンプレート削除後に全一覧空を確認。タスク作成・実行・モデル・クラウド呼び出しは行わない。これは実タスク移動の証明ではない。レポートは固定データと正規化した事実に限定し、認証・任意本文・パス・動的IDを含めない。全境界をキャンセル可とし自動再試行しない。

VMProbe --task-catalog は既存出力をディスク/VM作成前に拒否。同じ認証・停止・ログ監査境界で task-catalog-vm.json を作成。失敗時は所有マシンを停止し安全な段階だけ表示、失敗ディスクを保持。PATH からDockerを外しDOCKER_HOSTを無効にする。独立ブラウザのためDocker Desktopは起動中でもよく、Docker停止や未導入Macの証明とはしない。

比較環境は固定ARM64バックエンド/PostgreSQLイメージ、VMと同じ本体ハッシュを確認。専用内部ネットワーク、公開ポート・バインド・ソケットなし、バックエンドuid1000/DB999、読み取り専用ルートと使い捨てtmpfs、生成認証。Python固定検証をコンテナの/tmpへ転送し127.0.0.1のみへ接続。既存ブラウザの識別子維持と新規状態を確認。同じ有限手順のJSONを比較し、記録した所有コンテナ/ネットワークIDだけを既存清掃ヘルパーで削除。私有ログを保持し、生成した環境変数ファイルを削除。実画面は変更しない。

RED/GREEN・異常/キャンセル/完了試験、Python境界試験、レビュー、全体回帰、署名後に実VM1回と独立比較を実施する。実画面・タスク作成/実移動・再起動永続化・起動安定性・クラウド通信・全21機能・配布は未完了。
