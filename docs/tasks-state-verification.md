## Analyze and repair

5 Whys: cancelled navigation cleared valid detail → select changed local state before checking cancellation → transport/read cancellation guards run later → cancellation was tested only at request boundaries → add the guard at the local-state boundary and regress all three navigation inputs. Fishbone: response reordering, auth lifetime, selection identity, request cancellation, read versus mutation ownership, confirmation versus refresh failure, polling ownership, stopped operations. Timeline: fixed source and design → missing-store RED/GREEN10 → lifecycle expansion13 → review → cancelled-navigation runtimeRED → guard/GREEN14 → full regression/coverage → review/signed build.

The main-actor store keeps list/detail values and stale/error/loading state, active ID and canonical local selection. Separate UUID read tickets prevent old replies or defers from overwriting newer state. Selection never calls active-task mutation. One per-store gate serializes finite mutations and remains held across stop/reset until the actual operation terminates. Reset discards prior-session results/errors; stop preserves confirmation without spawning follow-up refresh. Confirmed mutations remain confirmed when their read refresh fails. Confirmed deletion removes only its owner immediately; other operations preserve aggregate list metrics until an authoritative list refresh. Partial batch receipts retain per-owner outcomes without raw error strings.

Mutations distinguish confirmed, local rejected, notStarted, unconfirmed and discarded. Unknown transport/cancellation results are not rollback evidence and are never retried automatically. Current selection may change while a mutation is pending; the receipt keeps the original owner and any refresh loads the current selected owner. Polling has one current owner, refreshes list/selected detail, sleeps10seconds and checks ownership/cancellation between awaits. An older stopped owner cannot clear a new owner's polling flag. Injectable sleep and controlled continuation responses prove order and gating without elapsed-time races.
