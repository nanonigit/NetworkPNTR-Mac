# エージェントのプロンプト保存の検証

Mac のエディターは固定ブラウザ版に合わせ、認証済みの `PUT /api/agents/{key}/prompt` でテンプレート原文と空のメモを送ります。保存すると新しい版が追加され、Go テンプレートの構文と変数名はゲストが検証します。拒否された下書きはそのまま編集できます。過去の版の読み込みは下書きに反映する操作です。未保存の下書きを閉じるときや置き換えるときは確認を表示します。

保存と履歴の読み込みは直列です。保存応答で版番号を受け取った場合は、直後の履歴にまだ反映されていなくても番号を表示します。保存結果が不明な場合は、次の保存操作の前に履歴の再読み込みを求めます。書き込みは自動で再送せず、応答が確認できなかった保存を成功として表示しません。同じ本文の版が増えることを避けるため、変更があるときに保存できます。

`e75ae371ad777ffd1eecdd28d2781a6519b05591` に固定した使い捨て Docker 参照環境では、Reporter の未定義変数を含む下書きが HTTP 400 で拒否され、履歴は変わりませんでした。有効なテンプレートは先頭の空白と改行を保って v2 として保存され、初版も残りました。エージェントは実行していません。編集と履歴の流れは固定ブラウザ版を基準とし、エディターから過去の版を開ける配置は Lazyweb の Notion と Canva の例も参考にしました。

署名済み Mac 版を隔離 Linux VM に接続して確認しました。参照版と同じ無効な下書きは拒否され、下書きと v1 が残りました。修正して保存すると v2 と v1 が履歴に並びました。v1 の読み込みは下書きだけに反映され、閉じるときに破棄確認が出ました。破棄後に開き直すと、先頭の空白を含む保存済み本文が表示され、現在の版は v2 でした。Mac の実画面を固定ブラウザ版の API と照合しました。認証後のブラウザ実画面との比較は残っています。

`swift test --filter AgentPromptEditorTests` で原文、拒否、通信途絶、履歴への未反映、同時操作を検証します。レンダリングのプレビュー、版の差分、既定値へのリセット、設定と権限、認証後のブラウザ実画面比較は後続の項目です。

Swift 1,065件とゲスト関連195件が成功し、既存の1件がスキップされました。リリースビルド、翻訳リソースの整合性とプレビューの署名を検証しました。使い捨て VM を停止し、検証用キーチェーン項目と状態、Docker 参照環境を削除しました。GitHub Actions は利用枠ポリシーに従いスキップしました。
