# 脆弱性調査ハーネスの追加設計

状態：ロードマップ案。ツールの導入・実行・ネットワーク有効化は未実装。既存ブラウザ版の21機能比較とリリース条件を維持する。今回はバックエンド／基盤設計のためLazyweb対象外。画面設計前には利用する。

## 目標

Macアプリから対象範囲・ツール・プロファイルを選択し、計画確認、実行、進捗、停止、資産／検出結果の確認、原文証跡の保存まで扱う。実行はLinux VM内のみ。ホストのシェル、共有フォルダ、Dockerソケット、汎用RPCを使わない。アプリ表示は英語／日本語のみ。外部ツールの中国語・韓国語出力は原文証跡として保持し、翻訳した説明と区別する。

## 構成

型付きタスク定義からゲスト専用アダプターを呼ぶ。定義にはビルド識別子、許可対象／除外範囲、URL／ポート、検査モジュール、通信速度・並列数・時間・出力量の上限、ネットワーク設定を含める。アプリとゲスト双方で検証し、固定バイナリを引数配列で起動する。シェル文字列を組み立てない。認証情報は別経路で渡し、ログや結果に残さない。

ゲストの監督プロセスが子プロセス群、出力上限、停止、異常終了を管理する。実行ID、変更不能な計画、時刻、終了状態、パーサー版を保存。失敗・部分結果・停止を「検出なし」と混同しない。資産・サービス・候補指摘へ正規化し、検出を脆弱性確定と扱わない。原文・成果物はハッシュ付きで既存の証跡／保存機能へ接続する。外部出力は信頼しないデータとして扱い、命令として解釈せず、表示とパスも制限する。

HTTP／通常TCPは非特権。raw packetとVPNの経路／インターフェース操作は、限定したゲストコンポーネントまたは別ゲートウェイVMへ分離する。最終構成は実験後に決定し、AIプロセスへrootやネットワーク管理権限を渡さない。ホストの経路設定を暗黙変更しない。現在のNICなしVMはネットワーク試験完了まで維持する。HTTPプロキシ許可だけではMasscanや任意VPN通信に対応できない。

出口で実際の接続先を制限する。IPv4／IPv6、DNS変化、リダイレクト、VPN経路を含める。VPN接続によって調査許可範囲は広がらない。再接続時の経路再検証、デフォルト経路／DNS漏洩防止、切断時の通信遮断、特権プロセス停止を試験する。資格情報、接続先の信頼確認、トンネル所有権は専用設計を要する。

## フェイズと完了条件

H0：共通のタスク／結果型、ライセンス・固定ビルド台帳、隔離試験ネットワーク。対象範囲検証、引数注入、出力上限、解析失敗、プロセス群停止、古い画面／セッション、秘密情報の伏せ字を試験。

H1：Dirsearch。所有するHTTP試験サービスで既知／不存在パス、ワイルドカード応答、範囲外転送、速度制限、認証情報保護、停止、再起動後の保存、原文ハッシュを検証。既存ブラウザにある操作は比較し、新規操作は独自のネイティブ受入条件を作る。

H2：Fscan。ラボの既知サービスで資産一覧、重複整理、不要モジュール無効、権限エラー、時間切れ、誤検知確認。影響を伴う検査プロファイルは別の受入後に追加。

H3：Masscan。隔離ネットワークのパケット観測で対象／速度／送信インターフェース、除外、NAT、精度、完全停止、権限分離を検証。raw通信不可の場合は通常TCP探索を代替選択肢にするが、同等の検査と偽って自動置換しない。

H4：SoftEther。所有するVPNラボで安定版／開発版を比較し、証明書異常、分割経路、重複ネットワーク、DNS／IPv6漏洩、再接続、切断時遮断、停止を試験。H1〜H3をVPN経由でも再試験。VPNは別途有効化する通信機能とし、直接接続のラボ試験の必須条件にしない。

H5：英日画面、キーボード／アクセシビリティ、共通タスク・指摘・証跡操作のブラウザ比較、クリーンMac導入、オフラインのツール台帳、署名、ロールバック、ソース／表示義務、完全な成果物保存。画面設計前にLazywebを利用。

各フェイズでRED／GREEN記録、隔離内の実ツール実行、期待値比較、出口／権限の拒否試験、停止／永続化の証拠、未完事項を残す。公開ネットワークを試験対象に使わない。CLIラッパーやモック、単体テストだけで完了としない。追加機能によって既存21機能の互換目標を完了扱いにしない。
