# T7 — 実添付と参照版の比較

T6はモデル/UI接続までで実転送は未検証。B1の修正ソースカーネル候補は単発起動成功1回のみで、過去panicは未解決・通常版へ未昇格です。旧/通常/比較版/失敗状態を保持し、新規の使い捨て状態で起動1回・有限期限の試験をします。同条件を成功まで繰り返しません。

Coreに本番認証クライアント/TaskStagingUploadingを使う有限の試験を追加。固定ファイル4つ：fixture.bin（決定的70001バイト）、empty.txt（0）、second/fixture.bin（別の短い本文）、日本-é.txt（決定的1280バイト）。CLIは自分の新規私有フォルダにだけ生成。初回保存名fixture.bin/empty.txt/fixture-1.bin/日本-é.txt、再送fixture-2.bin/empty-1.txt/fixture-3.bin/日本-é-1.txtを要求。下書き/名前/相対パス/サイズ/件数/順序、全ファイルの読戻しバイトとSHA256、再送後の初回読戻しで上書きなしを確認。await前後の取消を確認し自動再試行なし。読戻し先は検証済みUUID/固定名からだけ構築し、任意URLやabsをホストへ渡しません。既存4MiB応答上限内の少量データです。

結果は名前/相対パス/サイズ/ハッシュと、固定下書きルートだけを<draft>/uploads/へ置換した英日一覧。利用者情報を使わず、不足/別文脈/サイズ不正/部分応答/内容差異/エラーは成功扱いにしません。同一起動内の読戻しを再起動後の永続化と呼びません。

VMProbe --task-staging ARTIFACTS NEW_PRIVATE_OUTPUTは既存出力を起動前に原子的拒否。新規2GiB状態と秘密を生成し、未初期化認証/保護401を確認、メモリのみのVault/合成パスワードで新規口座だけ初期化。本番通信で試験し、ログアウト/正常停止後、全ログで隔離ゼロと秘密（接続/設定/JWT/パスワード）不在を監査。結果は固定段階/分類のみで生エラー/ログ/秘密/パスを出さず、失敗時は自分のVMを強制停止して状態を非公開保持。実行PATHにDockerを含めずDOCKER_HOSTも使用不能。ただしDocker Desktopは比較/ビルド用に稼働するためDocker停止/新規Mac合格とはしません。

参照版は固有名のDocker資源、検証済みARM64本体/PostgreSQLイメージ、公開ポート/ホスト共有/socketなし・内部ネットワークのみ。uid1000でコンテナ内127.0.0.1:8787へPython試験し、使い捨て明示フラグ/初期化前認証を必須にします。合成認証と同じ4ファイル/衝突名、/state/dataのabs、読戻し/上書きなし、固定ソースの日英ラベルによる正規化結果を比較。端末終了後、自分の参照資源だけ削除し安全なmanifest/statusと必要な非公開ログを保持。既存8787ブラウザは変更しません。純粋なappendUploadsはT6で比較済み、描画の合格とは別です。
